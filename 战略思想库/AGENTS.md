# 战略思想库 - 知识库管理规则

## 概述
本知识库收录古今中外伟大战略家的思想、战略案例和核心理论，旨在系统整理战略智慧的精华，供学习、研究和实践参考。

## 目录结构
```
战略思想库/
├── raw/           # 原始素材：未经整理的一手资料
├── wiki/
│   ├── 人物档案/   # 按战略家分类的详细档案
│   ├── 主题分类/   # 按主题归纳的战略思想
│   └── 经典案例/   # 历史上的经典战略战例
├── outputs/       # 生成的分析报告和综合研究成果
└── AGENTS.md      # 本规则文件
```

## 内容规范

### 人物档案格式
每位战略家的档案应包含：
- **基本信息**：生卒年、国籍、历史时期
- **人物简介**：生平概述、成就定位
- **核心战略思想**：3-5个主要思想体系
- **代表战略案例**：2-3个经典战例
- **经典语录/著作**：代表性名言和著作
- **后世影响**：对军事、政治、商业等领域的影响

### 主题分类格式
每个主题应包含：
- **主题定义**：概念的准确界定
- **核心原理**：主要理论要点
- **代表人物**：持有该观点的战略家
- **应用案例**：在历史中的应用

### 经典案例格式
每个战例应包含：
- **战役背景**：时间、地点、参战方
- **双方态势**：力量对比、战略意图
- **关键决策**：核心战略选择
- **战役经过**：主要阶段
- **胜负分析**：成败原因
- **战略启示**：对后世的指导意义

## 引用规范
- 每个观点需标注来源
- 使用[[链接]]语法建立内容关联
- 保持客观性，避免过度解读

## 更新机制
- 定期补充新内容
- 修正已发现的事实错误
- 根据反馈优化结构
