# 学习卡片模板

学习卡片是每日学习成果的精炼总结，包含以下核心内容：

## 核心结构

### 基本信息
- 学习日期、主题、时长、来源

### 核心知识点（3个）
- 每个知识点包含：核心内容、关键概念、关联理解

### 疑问（1个）
- 疑问内容、尝试解决、待解决方向

### 感悟（1个）
- 感悟内容、应用场景、延伸思考

### 进度记录
- 今日完成度、累计进度、明日计划

## 典型事项示例

### 示例 1：Python 学习卡片（Day 1）

**基本信息**
- 日期: 2026-01-06
- 主题: Python 基础语法 - 变量与数据类型
- 时长: 2.5 小时
- 来源: Python 官方教程

**核心知识点**
1. 变量的概念与使用 - 变量是存储数据的容器，通过赋值语句创建
2. Python 的基本数据类型 - 数字、字符串、列表、元组、字典、集合
3. 类型转换与类型检查 - 使用 `type()` 和 `int()` 等函数

**疑问**
- 为什么 Python 是动态类型语言？如何自动推断变量类型？

**感悟**
- Python 的动态类型可以快速尝试想法，但可能引入运行时错误

**进度**
- 完成度: 100%
- 累计: 5%
- 明日: 控制流（if 语句和循环）

### 示例 2：面向对象编程学习卡片（Day 5）

**基本信息**
- 日期: 2026-01-10
- 主题: 面向对象编程 - 类与对象
- 时长: 3 小时
- 来源: Python Crash Course - Chapter 9

**核心知识点**
1. 类与对象的关系 - 类是蓝图，对象是实例化结果
2. 方法定义与 self 参数 - `self` 代表实例本身
3. 构造函数 `__init__` - 创建对象时自动调用，用于初始化属性

**疑问**
- 类属性和实例属性有什么区别？什么时候该用哪个？

**感悟**
- 面向对象编程的核心是封装，通过类将数据和方法封装在一起

**进度**
- 完成度: 100%
- 累计: 25%（第一阶段完成）
- 明日: 继承和多态

### 示例 3：雅思口语学习卡片（Day 3）

**基本信息**
- 日期: 2026-01-08
- 主题: 雅思口语 Part 1 - 话题准备
- 时长: 1.5 小时
- 来源: 雅思口语题库 + 在线资源

- 如何让 Part 1 的回答不显得背诵痕迹太重？

**感悟**
- 自然表达比复杂词汇更重要，注重流利度和连贯性

**进度**
- 完成度: 100%
- 累计: 15%
- 明日: Part 2 话题准备

## 呈现方式建议

### 视觉化信息图（生图工具）
使用生图工具创建学习卡片信息图，包含：
- 顶部：基本信息（日期、主题、时长）
- 中间：3个核心知识点（配图标）
- 底部：疑问、感悟、进度

### 可视化图表
使用可视化图表创建思维导图，展示知识点之间的层次和关联。

### 混合呈现（推荐）
- 生成信息图供保存回顾
- 生成思维导图展示知识结构
- 对话中输出文本版本提供详细信息

## 注意事项

- 每个知识点用自己的话复述，避免直接复制
- 疑问要具体明确，感悟要有深度
- 进度记录要真实
- 根据用户偏好选择合适的呈现方式
