# 日常跟进类示例

本目录展示日常跟进型目标的典型 Agent 生成事项，适用于行业动态调研、信息收集等场景。

## 典型事项示例

### 示例 1：AI 领域动态调研 - 信源管理

**主要信源**
- 技术博客：OpenAI Blog、Anthropic Blog、Google AI Blog、Hugging Face Blog
- 论文平台：arXiv.org（cs.AI、cs.CL、cs.LG）
- 新闻资讯：The Verge AI、TechCrunch AI、36氪 AI
- 社交媒体：Twitter/X（@OpenAI、@AnthropicAI）

**筛选标准**
- 优先级：官方公告 > 重要论文 > 突发新闻 > 次要新闻
- 过滤规则：忽略重复报道、低质量内容；关注技术突破、产品发布、行业重大事件
- 更新频率：实时（Twitter）、每日（博客/新闻）、每周（论文）

**阅读框架**
- 快速浏览（15 分钟）：浏览标题，判断重要性，阅读摘要，标记重要文章
- 深度阅读（30 分钟）：精读方法部分、实验细节、相关工作，记录笔记

### 示例 2：AI 领域动态调研 - Day 1 执行事项

**Agent 可生成的增强内容**

1. **联网搜索** - 验证信源时效性
   - 搜索"OpenAI Anthropic Google AI Blog latest updates 2026"
   - 验证各博客是否持续更新，提取最新文章发布时间

2. **网页读取** - 深度挖掘最新内容
   - 读取 OpenAI Blog 最新文章，提取标题、发布时间、核心内容
   - 识别技术突破点，提取关键数据（模型性能、参数量等）

3. **数据可视化** - 生成技术趋势图
   - 基于本周收集的技术动态，生成技术趋势词云
   - 展示本周最热门的技术关键词

4. **表格处理** - 知识库构建
   - 创建 Excel 知识库模板，包含：日期、来源、标题、核心观点、关键数据、个人笔记
   - 自动分类：按主题（大模型、多模态、应用等）分类

5. **生成 PPT** - 信息简报
   - 生成每日信息简报 PPT，包含：标题、摘要、链接、重要性评级

**数据收集方式**
- Agent 主动询问："今天浏览了哪些重要动态？有哪些印象深刻的突破？"
- 用户自然语言回答，Agent 自动整理和记录到知识库

### 示例 3：AI 领域动态调研 - Week 1 能力运用

**Day 1-5（工作日）**：
- 联网搜索：每日浏览技术博客和新闻
- 网页读取：提取最新文章的核心内容
- 数据可视化：生成每日技术趋势词云
- 表格处理：自动记录到知识库（按主题分类）

**Day 6（周六）**：
- 精读本周标记的重要文章
- 网页读取：深度挖掘论文或技术博客
- 生成 PPT：精读笔记 PPT（核心观点、技术细节、思考）

**Day 7（周日）**：
- 表格处理：汇总本周所有动态到知识库
- 数据可视化：生成本周技术趋势图、主题分布饼图
- 生成 PPT：周度总结 PPT（本周重要动态、技术趋势、下周关注重点）

### 示例 4：行业动态调研 - 周度总结事项

**Agent 可生成的增强内容**

1. **表格处理** - 汇总本周数据
   - 自动统计：阅读文章数量、按主题分类统计、重要文章列表
   - 计算指标：技术热度、新闻频次、新出现的技术方向

2. **数据可视化** - 周度技术趋势分析
   - 技术趋势折线图：展示本周各技术领域的热度变化
   - 主题分布饼图：展示本周关注的主题分布（大模型、多模态、应用、安全等）
   - 关键词云：展示本周最热门的技术关键词
   - 信源分布图：展示本周主要信息来源（OpenAI、Anthropic、Google、媒体等）

3. **视觉设计** - 行业动态信息图
   - 生成本周行业动态信息图，包含：重要技术突破、产品发布、行业事件
   - 时间线展示本周关键事件
   - 配色：科技感（蓝、紫、灰）

4. **生成 PPT** - 周度总结报告
   - 本周重要动态概览
   - 技术趋势分析（可视化图表）
   - 精读文章总结
   - 下周关注重点

### 示例 5：月度回顾事项

**Agent 可生成的增强内容**

1. **表格处理** - 月度数据汇总
   - 汇总本月所有动态到月度知识库
   - 统计指标：总阅读文章数、各主题文章数、重要文章列表、技术演进轨迹

2. **数据可视化** - 月度技术趋势分析
   - 技术趋势折线图：展示本月各技术领域的热度变化趋势
   - 主题分布饼图：展示本月关注的主题分布
   - 新技术涌现图：展示本月新出现的技术方向
   - 信源可靠性分析：展示各信源的重要性和可靠性

3. **视觉设计** - 月度行业动态信息图
   - 生成月度行业动态信息图，包含：重要技术突破、产品发布、行业事件、技术演进
   - 时间线展示本月关键事件
   - 对比展示月初与月末的技术变化

4. **生成 PPT** - 月度总结报告
   - 本月重要动态概览
   - 技术趋势分析（可视化图表）
   - 技术演进轨迹
   - 下月预测和关注重点

## 注意事项

- 所有数据收集通过自然语言对话完成，用户无需手动填写表格
- Agent 自动完成所有计算、整理、记录工作
- 根据用户反馈动态调整信息筛选标准和阅读框架
- 定期回顾和更新信源列表，确保信息质量
