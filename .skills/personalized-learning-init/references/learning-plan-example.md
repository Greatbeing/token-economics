# 学习类计划示例

本目录展示能力进阶型目标的典型 Agent 生成事项，适用于编程学习、考试备考等场景。

## 典型事项示例

### 示例 1：Python 学习计划 - 学习路径规划

**学习目标**
- 主题: Python 编程
- 达成标准: 能独立开发简单的 Web 应用（后端开发）
- 核心动机: 转行从事后端开发

**学习路径（四阶段）**

**第一阶段：入门（3 周）**
- 目标: 掌握 Python 基础语法
- 内容: 变量与数据类型、控制流（if/for/while）、函数基础、基本数据结构（列表、字典、元组）
- 资源: Python 官方文档、Python Crash Course、FreeCodeCamp
- 成果: 完成一个小型计算器项目

**第二阶段：基础（4 周）**
- 目标: 掌握面向对象编程和常用标准库
- 内容: 类与对象、继承与多态、文件操作、异常处理、常用标准库（os, sys, json, requests）
- 资源: Python Crash Course（进阶部分）、Real Python
- 成果: 完成一个文件管理工具

**第三阶段：进阶（5 周）**
- 目标: 掌握 Web 开发框架和数据库
- 内容: Flask/Django 框架基础、数据库操作（SQL + ORM）、RESTful API 设计、前端基础（HTML/CSS/JavaScript）
- 资源: Flask 官方文档、Two Scoops of Django、FreeCodeCamp 前端课程
- 成果: 完成一个简单的 REST API

**第四阶段：实战（6 周）**
- 目标: 独立开发完整的 Web 应用
- 内容: 用户认证与授权、部署（Docker/云服务）、测试（单元测试、集成测试）、性能优化
- 资源: Flask Mega-Tutorial、Docker 官方文档
- 成果: 部署个人博客系统

**执行配置**
- 每日投入: 工作日 2 小时，周末 4 小时
- 学习风格: 实战驱动
- 验收方式: 每阶段项目验收 + 每日测验

### 示例 2：Python 学习计划 - Day 1 执行事项

**今日学习内容**
- 基础语法：变量与数据类型
- 实践：编写第一个 Python 脚本

**Agent 可生成的增强内容**

1. **联网搜索** - 搜索 Python 最新最佳实践
   - 搜索"Python 3.12 best practices 2026"
   - 获取最新的语法特性和编程规范

2. **网页读取** - 提取官方教程核心内容
   - 读取 Python 官方文档 Tutorial 第 3 章
   - 提取变量赋值、数据类型、类型转换的示例代码和解释

3. **视觉设计** - Python 数据类型信息图
   - 信息图展示 6 种基本数据类型（数字、字符串、列表、元组、字典、集合）
   - 每种类型包含：图标、定义、示例代码、常用操作
   - 配色：Python 官方配色（蓝、黄）

4. **生成 PPT** - Day 1 学习总结 PPT
   - 核心知识点总结、示例代码展示、练习题讲解、明日计划

5. **交互式测试** - 基础语法测验
   - 生成 3-5 道选择/判断题，测试变量和数据类型掌握情况
   - 即时反馈，显示正确答案和解释

**学习卡片生成**
- 生成 Day 1 学习卡片（见 learning-card-template.md）
- 包含：3 个核心知识点、1 个疑问、1 个感悟、进度记录

**数据收集方式**
- Agent 主动询问："今天学习感觉怎么样？有哪些地方不太理解？"
- 用户自然语言回答，Agent 自动记录到学习卡片和知识库

### 示例 4：雅思备考计划 - 学习路径规划

**学习目标**
- 主题: 雅思考试（IELTS）
- 达成标准: 总分 7.0（听力 7.5、阅读 7.5、写作 6.5、口语 6.5）
- 核心动机: 申请研究生

**学习路径（四阶段）**

**第一阶段：基础夯实（3 周）**
- 目标: 熟悉考试题型，掌握基础词汇和语法
- 内容: 词汇积累（每天 50 个）、语法巩固、四科题型介绍
- 资源: 雅思词汇书、剑桥雅思真题 1-4、语法教材
- 成果: 完成词汇量测试，掌握所有题型

**第二阶段：单项突破（4 周）**
- 目标: 各单项达到目标分数
- 内容:
  - 听力：精听训练、同义词替换、笔记技巧
  - 阅读：快速阅读、定位技巧、长难句分析
  - 写作：Task 1 图表描述、Task 2 议论文结构、高级词汇句型
  - 口语：Part 1 话题准备、Part 2 话题卡、Part 3 深度讨论
- 资源: 剑桥雅思真题 5-10、Simon IELTS、雅思口语题库
- 成果: 各单项模拟测试达到目标分数

**第三阶段：综合提升（3 周）**
- 目标: 提升综合应试能力
- 内容: 全真模拟测试、错题分析、技巧强化
- 资源: 剑桥雅思真题 11-18、预测题
- 成果: 完成 10 套全真模拟测试

**第四阶段：冲刺备考（2 周）**
- 目标: 调整状态，查漏补缺
- 内容: 轻松复习、保持语感、调整作息、考前准备
- 资源: 错题本、高频词汇、口语话题卡
- 成果: 考试

**执行配置**
- 每日投入: 工作日 2 小时，周末 4 小时
- 学习风格: 技巧 + 实战结合
- 验收方式: 每周模拟测试 + 错题分析
