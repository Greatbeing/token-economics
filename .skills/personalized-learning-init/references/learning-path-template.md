# 学习路径规划模板

学习路径规划书用于指导目标达成，根据目标类型采用不同的规划方式。

## 核心结构

### 1. 学习目标
- 主题、达成标准、核心动机

### 2. 能力现状评估
- 当前水平、优势、待提升

### 3. 目标类型
- A 类：能力进阶型（学编程、考证、技能提升）
- B 类：习惯养成型（健康饮食、每日锻炼）
- C 类：日常跟进型（读论文、行业调研）

### 4. 执行路径规划（根据类型）

#### A 类（能力进阶型）：四阶段路径
- 第一阶段：入门
- 第二阶段：基础
- 第三阶段：进阶
- 第四阶段：实战

#### B 类（习惯养成型）：习惯养成机制
- 触发条件
- 执行步骤
- 奖励机制

#### C 类（日常跟进型）：信息筛选机制
- 信源管理
- 筛选标准
- 阅读框架

### 5. 优质资源索引库
- 每阶段 3-5 个高质量资源
- 包含：名称、类型、适用人群、时效性

### 6. 执行配置
- 每日投入时间
- 学习风格偏好
- 验收方式

## 典型事项示例

### 示例 1：Python 编程学习路径（A 类 - 能力进阶型）

**学习目标**
- 主题: Python 编程
- 达成标准: 能独立开发简单的 Web 应用
- 核心动机: 转行从事后端开发

**能力现状**
- 当前水平: 零基础
- 优势: 有逻辑思维能力
- 待提升: 缺乏编程思维和实践经验

**学习路径（四阶段）**

**第一阶段：入门（3 周）**
- 目标: 掌握 Python 基础语法
- 内容: 变量、数据类型、控制流、函数、基础数据结构
- 资源: Python 官方文档、廖雪峰 Python 教程
- 成果: 完成一个小型计算器项目

**第二阶段：基础（4 周）**
- 目标: 掌握面向对象编程和标准库
- 内容: 类与对象、文件操作、异常处理、常用标准库
- 资源: Python Crash Course、Real Python
- 成果: 完成一个文件管理工具

**第三阶段：进阶（5 周）**
- 目标: 掌握 Web 开发框架和数据库
- 内容: Flask/Django、数据库操作、RESTful API
- 资源: Flask 官方文档、Two Scoops of Django
- 成果: 完成一个简单的 REST API

**第四阶段：实战（6 周）**
- 目标: 独立开发完整的 Web 应用
- 内容: 用户认证、部署、测试、性能优化
- 资源: Docker 官方文档、Flask Mega-Tutorial
- 成果: 部署个人博客系统

**执行配置**
- 每日投入: 2-3 小时
- 学习风格: 实战导向
- 验收方式: 每阶段项目验收

### 示例 2：健康饮食计划（B 类 - 习惯养成型）

**学习目标**
- 主题: 健康饮食改善
- 达成标准: 3 个月减重 5kg，精力水平提升
- 核心动机: 改善健康、提高生活质量

**能力现状**
- 当前水平: 饮食不规律，经常外卖
- 优势: 有时间在家做饭
- 待提升: 减少外卖，增加蔬菜，控制甜食

**习惯养成机制**

**触发条件**
- 早餐: 每天早上 7:30（固定时间）
- 晚餐: 每天晚上 7:00（固定时间）

**执行步骤**
- 早餐（30 分钟）: 高蛋白 + 全谷物 + 水果
- 晚餐（60 分钟）: 优质蛋白 + 大量蔬菜 + 复合碳水
- 日常: 每天 2L 水，零食替换为坚果水果

**奖励机制**
- 每日奖励: 坚持一天饮食计划，可以看电影或听音乐
- 每周奖励: 坚持一周，享受一次 cheat meal
- 里程碑奖励: 减重 2kg，买一件新衣服

**优质资源**
- 中国居民膳食指南（2022）- 官方文档
- 轻断食方法 - 科研文章
- 健康食谱 app - 移动端

**执行配置**
- 每日投入: 90 分钟
- 执行风格: 简化饮食指南
- 验收方式: 习惯打卡 + 数据记录

### 示例 3：AI 领域动态跟进（C 类 - 日常跟进型）

**学习目标**
- 主题: AI 领域最新动态调研
- 达成标准: 每周掌握 5-10 篇重要论文的核心内容
- 核心动机: 保持行业敏感度，为研究和工作提供灵感

**能力现状**
- 当前水平: 有一定 AI 基础
- 优势: 有技术背景，能理解论文内容
- 待提升: 系统化的信息筛选和消化机制

**信息筛选机制**

**信源管理**
- 主要信源: arXiv、顶级会议（NeurIPS、ICML、ACL）、行业博客（OpenAI、Anthropic）
- 筛选标准: 相关性（主题匹配）、影响力（引用数、作者）、新颖性（创新点）
- 更新频率: 每日筛选，每周深度阅读 3-5 篇

**阅读框架**
- 快速浏览（5 分钟/篇）: 标题、摘要、结论、实验结果
- 深度阅读（30 分钟/篇）: 方法部分、实验细节、相关工作
- 输出方式: 简报总结、核心要点笔记、脑图整理

**执行配置**
- 每日投入: 30 分钟（筛选）+ 1 小时（深度阅读）
- 阅读风格: 批量处理，主题聚焦
- 验收方式: 每周简报 + 季度综述

## 注意事项

- 根据目标类型选择合适的规划方式
- 资源优先选择官方文档、权威专栏、优质视频频道
- 执行配置应结合用户的实际情况（时间、基础、偏好）
