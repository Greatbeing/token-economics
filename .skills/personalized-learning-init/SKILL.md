# 个性化学习提升计划初始化

本技能旨在帮助用户制定并执行高效的个性化目标计划，从目标拆解到落地执行。适用于学习计划、个人技能提升、健康管理等多种场景。

## 任务目标
- 帮助用户澄清目标（ORA 框架）
- 生成 Day 0 初始化任务清单
- 建立可持续多周循环执行的每周执行模式
- 启动 Day 1 正式执行并持续迭代

## 前置准备
无需额外依赖，所有功能由智能体自然语言指导完成。

## 操作步骤

### 步骤 1：目标对齐与拆解（ORA 框架）

引导用户澄清以下 ORA 信息：

**Objective (目标)**
- 目标主题：想达成什么？（学习主题、技能领域、健康目标等）
- 达成标准：达成什么程度？（具体标准、量化指标）
- 核心动机：为了什么？（职业发展、个人兴趣、健康改善等）

**Requirements (要求)**
- 时间投入：每天/每周能花多少时间？
- 偏好风格：喜欢什么方式？（学习类：看视频/读文档/实战；健康类：渐进式/挑战式）
- 现有基础：当前水平如何？（零基础、有经验、需要专业指导）
- 信息源偏好：是否有偏好的学习资源索引和信息源？（如：官方文档、特定书籍、博主/专栏、视频频道等。如果需要推荐，将在学习大纲撰写时一并搜索和确认）

**Actions (关键动作)**
- Day 0：完成现状评估、执行路径规划、资源/方法搜集与筛选
- Week 1：进入"计划-执行-复盘"的闭环循环

### 步骤 2：Day 0 初始化任务清单

使用 `create_plan_item` 工具创建以下两个 Day 0 立即执行事项：

#### 任务 1：领域知识搜索与学习大纲规划
**执行内容**：
1. **领域知识搜索**：根据确认的目标方向，执行深度搜索（Deep Research）
   - 了解该领域的核心知识体系和学习路径
   - 收集该领域的标准大纲、经典教材、权威指南
   - 如果用户提供了信息源偏好，重点从这些信源获取知识
   - 如果用户需要推荐，搜索并筛选适合该用户水平和目标的优质信息源

2. **目标类型识别与学习大纲规划**：
   - **类型 A - 能力进阶型**（如学编程/考证/技能提升）：
     - 搜索标准路线图，拆解为"入门-基础-进阶-实战"四阶段
     - 明确第一阶段的学习重点和里程碑
   - **类型 B - 习惯养成型**（如健康饮食/每日锻炼）：
     - 制定《习惯养成机制》，明确触发条件、执行步骤、奖励机制
     - 规划渐进式的提升路径
   - **类型 C - 日常跟进型**（如读论文/行业调研）：
     - 制定《信息筛选与消化机制》，明确信源、筛选标准、阅读框架

3. **学习大纲撰写**：
   - 根据用户的目标类型、当前水平和希望的时间节奏
   - 撰写详细的《学习大纲》或《执行路径规划书》
   - 包含：阶段划分、每周重点、关键里程碑、验收标准
   - 如果用户需要推荐，在学习大纲中一并列出后续持续生成每日学习内容时使用的信息源偏好

4. **与用户对齐确认**：
   - 向用户展示《学习大纲》或《执行路径规划书》
   - 确认是否符合预期，是否需要调整

**产出**：生成《学习大纲》或《目标执行路径规划书》，参考格式见 [references/learning-path-template.md](references/learning-path-template.md)

#### 任务 2：内容产物设计与试学内容生成
**执行内容**：
1. **内容形态设计**：根据目标类型和用户偏好，设计适合的学习内容产物形式
   - **视觉系**：信息图、思维导图、PPT 幻灯片、训练计划表、饮食计划表
   - **文本系**：深度文档、简报、对话直接输出、食谱、训练指南
   - **交互系**：打卡清单、进度跟踪表、代码 Notebook、练习题集

2. **验收机制设计**：与用户确认是否需要测试来跟踪学习进展
   - **知识测验**：每日/每周生成 3-5 道选择/判断题（适用于学习类）
   - **动手实操**：布置每日/每周任务或练习（适用于技能类）
   - **费曼复述**：要求用户向 AI 解释核心概念（适用于学习类）
   - **习惯打卡**：记录执行情况与感受（适用于健康类）
   - **数据记录**：记录关键指标（如体重、运动时长、饮食记录、精力评分）
   - **综合评估**：周度/月度自测，检验整体掌握情况

3. **试学内容生成**：
   - 根据设计的内容形态和验收机制，生成第一个试学/试执行内容
   - 内容应包含：
     - 核心知识点/执行步骤
     - 练习题/实操任务（根据验收机制）
     - 适合用户水平的难度设置
   - 目的：让用户了解后续每日学习的内容形态、难度是否符合预期

4. **与用户对齐确认**：
   - 让用户试看/试执行第一个试学内容
   - 确认内容形态是否符合偏好（视觉/文本/交互）
   - 确认难度是否合适（太难/太简单/刚好）
   - 确认是否需要每日/每周测试来跟踪学习进展
   - 根据反馈调整内容设计和难度设置

**产出**：
- 第一个试学/试执行内容
- 《个性化执行配置单》（内容形态 + 验收机制）

**依赖**：依赖任务 1 的学习大纲

#### 任务 3：建立每周循环执行模式（在任务2确认后立即执行）

**重要**：在完成试学内容用户确认后，立即建立"计划-执行-复盘"的每周循环执行模式，确保用户清楚了解后续多周的持续执行模式。此模式将适用于 Week 1、Week 2、Week 3 等所有周次的循环。

按照"计划-执行-复盘"循环或"费曼学习法"规划：

**Day 1 - Day 7：每日微习惯（固定）**
- 任务：
  1. 执行今日计划（约 X 小时或按目标执行）
  2. 输出一份《今日执行卡片》，参考格式见 [references/learning-card-template.md](references/learning-card-template.md)
    - 包含：3 个核心收获/进展、1 个疑问/困难、1 个感悟/调整

**Day 1, 3, 5：深度输入/计划更新（动态内容生成）**
- 任务：
  1. **内容生成**：根据今日主题，执行深度搜索（Deep Research）。结合最新动态或科学依据，生成《定制执行简报》、《核心知识图解》或《健康/训练指南》
  2. **内容摄取**：阅读/观看生成的简报及辅助资源/方法。重点：理解核心要点，做好记录

**Day 2, 4, 6：实战演练/习惯强化（技能内化）**
- 任务：
  1. **任务生成**：基于昨天内容，生成《实战练习题》、《训练计划》、《饮食清单》或《代码挑战任务》（包含执行要点）
  2. **执行练习**：完成任务，并尝试向 AI 复述执行过程和感受

**Day 7：周度复盘与测验**
- 任务：
  1. 整理本周《执行卡片》，生成《周进展脑图》或《复盘报告》
  2. 进行一次自测或数据评估（找习题/指标/由 AI 出题）
  3. 调整下周计划（进度快了还是慢了？强度如何？）

**产出**：每周循环执行模式说明（适用于 Week 1、Week 2、Week 3 等所有周次，包含 Day 1-7 的标准执行流程）

### 步骤 3：Day 1 正式启动与持续循环

**重要**：在完成 Day 0 三个任务（任务1、任务2、任务3）并得到用户确认后，Day 1 立即进入正式执行流程，并按周持续循环：

1. **立即执行 Day 1 任务**：生成今日份《执行简报》或《行动计划》
   - 根据已确认的内容形态、难度设置和验收机制生成
   - 根据学习大纲的第一阶段重点，生成今日学习内容
   - 用户按每周循环执行模式执行并输出《今日执行卡片》

2. **持续多周循环执行**：
   - Week 1-Week N：每周重复"计划-执行-复盘"循环
   - 每周根据学习大纲的阶段性重点调整内容
   - 每周日进行周度复盘，根据进展调整下周计划
   - 直至达成目标或按需调整计划

## 注意事项
- 创建任务时，确保 `description` 字段包含完整的指令，明确"产出什么"
- 所有内容由智能体自然语言生成，无需脚本支持
- **Day 0 任务 1 必须先搜索领域知识并生成学习大纲，与用户确认后才能进入任务 2**
- **Day 0 任务 2 必须试生成试学内容并让用户试看/试执行，对齐内容形态、难度、测试方式后才能进入任务 3**
- **Day 0 任务 3 必须在试学内容用户确认后立即建立每周循环执行模式，让用户清楚了解后续多周的持续执行方式**
- 每周循环执行模式适用于 Week 1、Week 2、Week 3 等所有周次，不是仅限第一周
- 每周日根据实际进展进行周度复盘，动态调整下周计划和学习重点
- Day 0 已通过试学内容完成反馈确认，Day 1 直接进入正式每日学习流程
- 根据不同目标类型（学习/技能/健康）调整执行策略和验收方式
- 充分利用智能体的内容创作能力和深度搜索能力，生成个性化的执行材料
- 信息源偏好已在步骤 1 Requirements 中确认，如需推荐应在学习大纲撰写时一并搜索和确认
