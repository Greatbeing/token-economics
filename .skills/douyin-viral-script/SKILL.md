# 抖音爆款口播文案生成器

## 任务目标
- 本 Skill 用于：根据任意话题或书籍快速生成符合抖音爆款逻辑的口播文案
- 能力包含：提炼核心观点、设计密集钩子、把握抖音节奏、情绪调动引导
- 触发条件：用户需要为抖音视频创作口播文案

## 操作步骤
- 标准流程:
  1. **理解输入**:分析用户提供的话题或书籍，提炼核心观点和情绪点
  2. **设计钩子**:根据「钩子技巧参考」中的方法，设计开头钩子和中间钩子
  3. **生成文案**:按照「爆款文案结构」模板，生成约600字的口播文案
  4. **优化节奏**:检查钩子密度、情绪调动、黄金3秒原则是否符合要求

- 质量标准:
  - 开头必须有强钩子，3秒内抓住注意力
  - 文案中钩子密集分布，每10-15秒一个钩子
  - 情绪曲线起伏，有共鸣点和情绪高潮
  - 结尾有明确引导（点赞、关注、评论）
  - 字数控制在600字左右，语速适合口播

## 爆款文案结构

### 开头（前50-80字）
- **黄金3秒钩子**：用一个强烈的疑问、反常识、数字冲击、痛点戳中
- 快速切入主题，不拖泥带水
- 示例：「你绝对想不到...」「99%的人都在犯这个错...」「为什么你的努力没用？」

### 中间（300-400字）
- **钩子密集分布**：每10-15秒（约40-60字）插入一个钩子
- **价值输出**：提供有用信息、方法论、观点
- **情绪调动**：共情、焦虑、兴奋、希望等情绪切换
- **故事化表达**：用案例、对比、场景增强代入感

### 结尾（100-150字）
- **情绪高潮**：总结升华，激发行动欲
- **明确引导**：引导点赞、关注、评论
- **留下悬念**：引发思考和讨论

## 注意事项
- 文案要口语化，避免书面语和长难句
- 用短句为主，节奏快，适合口播
- 情绪要真实，避免夸张和虚假
- 价值输出要具体，避免空洞说教
- 根据目标受众调整语言风格

## 使用示例

### 示例1：话题类文案
**输入**：「如何提升工作效率」

**输出结构**：
- 开头钩子：「你每天工作10小时，为什么还是没成果？」
- 中间钩子+价值：「第一个误区...」「第二个致命点...」「3个技巧...」
- 结尾引导：「关注我，送你效率工具包」

### 示例2：书籍类文案
**输入**：《原子习惯》

**输出结构**：
- 开头钩子：「为什么90%的人改变失败？」
- 中间钩子+价值：「作者10年研究...」「3步养成好习惯...」「每天5分钟...」
- 结尾引导：「评论区扣'改变'，领读书笔记」

- **无脚本依赖**：所有功能通过自然语言指导完成，无需技术脚本
- **参考文档**：提供钩子技巧和案例库，辅助智能体生成高质量文案
