## 二、分平台入驻指南

### 2.1 喜马拉雅

**入驻流程**：
1. 下载喜马拉雅App
2. 点击"账号"→"创作者中心"
3. 选择"我要做主播"
4. 填写节目信息
5. 上传音频

**节目设置建议**：
```
名称：和古人一起想问题
分类：儿童 > 故事 > 传统文化
标签：儿童哲学、中国智慧、亲子教育、国学、睡前故事
简介：穿越时空，和古代大思想家一起想问题！
      用故事和比喻，把深奥的哲学变成好玩的冒险！
      适合8-12岁儿童及家长
封面：500×500px，JPG/PNG
```

**运营建议**：
- 每周固定时间更新（如周六早8点）
- 积极参与"喜马拉雅儿童"话题
- 回复听众评论，增加互动

---

### 2.2 小宇宙

**入驻流程**：
1. 下载小宇宙App
2. 使用手机号注册
3. 点击"+"创建播客
4. 填写RSS信息或直接上传

**节目设置建议**：
```
名称：和古人一起想问题
简介：穿越时空，和古代大思想家一起想问题！
标签：#儿童 #哲学 #亲子 #中国智慧
```

**运营建议**：
- 小宇宙用户更喜欢深度内容
- 评论区回复要真诚、有深度
- 可以创建播客群与听众交流

---

### 2.3 网易云音乐

**入驻流程**：
1. 下载网易云音乐App
2. 点击"账号"→"创作者中心"
3. 选择"电台"/"播客"入驻
4. 完善信息后上传音频

**节目设置建议**：
```
名称：和古人一起想问题
分类：亲子 > 儿童故事 > 国学启蒙
标签：儿童哲学、亲子教育、国学启蒙
简介：和孩子一起听哲学，做有智慧的父母
```

---

### 2.4 QQ音乐

**入驻流程**：
1. 下载QQ音乐App
2. 点击"账号"→"创作者平台"
3. 选择"电台"/"播客"入口
4. 填写信息入驻

**节目设置建议**：
```
名称：和古人一起想问题
分类：亲子天地 > 儿童故事
标签：儿童哲学、亲子教育、国学
```

**运营建议**：
- QQ音乐青少年用户多
- 内容要活泼有趣
- 可与QQ群、微信群联动推广

---

### 2.5 蜻蜓FM

**入驻流程**：
1. 访问蜻蜓FM官网或下载App
2. 点击"主播入驻"
3. 填写主播信息
4. 申请创建节目

**节目设置建议**：
```
名称：和古人一起想问题
分类：亲子 > 儿童教育 > 国学
标签：儿童哲学、亲子教育、国学启蒙
简介：用故事讲解中国哲学，适合亲子共听
```

---

### 2.6 Apple Podcasts（国际版）

**入驻方式**：
通过Apple Podcast Connect后台管理

**要求**：
- 需要Apple ID
- 建议准备英文版简介
- 封面需300dpi（1400×1400px）

**英文简介模板**：
```
An ancient philosophy adventure for kids!

Join Xiaoxing as she time-travels to meet ancient Chinese thinkers like Laozi, Confucius, and Zhuangzi. Through stories and analogies, children will explore deep philosophical questions in a fun way.

Perfect for kids aged 8-12 and their parents.

Keywords: Chinese philosophy, kids education, bedtime stories, parent-child
```

## 三、发布策略

### 3.1 发布节奏建议

#### 方案A：每周更新（推荐）
| 周次 | 发布内容 |
|------|----------|
| 第1周 | 第1集 + 封面 + 简介 |
| 第2周 | 第2集 |
| 第3周 | 第3集 |
| ... | ... |
| 第12周 | 第12集 |
| 第13周 | 番外篇/彩蛋 |

#### 方案B：集中上线
- 适合：已提前制作完成全部内容
- 方式：一次性上传12集
- 优势：可设置合集专辑

### 3.2 宣传推广计划

- [ ] 建立粉丝群（微信/QQ）

#### 发布期
- [ ] 同步在各平台发布
- [ ] 在家长群/教育群推广
- [ ] 邀请首批听众反馈

#### 稳定期
- [ ] 每周固定时间更新
- [ ] 整理听众问题，创作番外

## 六、检查清单

### 发布前检查
- [ ] 封面图片：尺寸符合要求、无水印
- [ ] 音频格式：MP3、128kbps以上
- [ ] 标题：简洁、包含关键词
- [ ] 简介：300字以内，突出亮点
- [ ] 标签：5-10个相关标签

### 发布后检查
- [ ] 确认音频已上线
- [ ] 检查封面显示是否正常
- [ ] 测试音频播放是否流畅
- [ ] 在各平台搜索确认可见
