# 《和古人一起想问题》封面设计需求

## 整体风格

### 视觉定位
- **风格**：温暖治愈 + 奇幻冒险 + 中国传统文化元素
- **色调**：深蓝星空为主色，金色/暖黄为点缀色
- **氛围**：神秘、温暖、充满想象力

### 目标受众视觉偏好
- 吸引8-12岁儿童：活泼但不过幼稚
- 吸引家长：有文化内涵、品质感
- 适合收藏和分享

---

## 主封面设计要求

### 尺寸规格
| 平台 | 尺寸要求 | 用途 |
|------|----------|------|
| 喜马拉雅 | 500×500px | 主封面 |
| 小宇宙 | 300×300px | 小封面 |
| Apple Podcasts | 1400×1400px (300dpi) | 高清封面 |
| QQ音乐/网易云 | 500×500px | 音乐平台封面 |

### 元素构成

#### 1. 背景层
- 深蓝色渐变星空背景
- 隐约可见的星座图案（如北斗七星）
- 可选：极光或流星元素

#### 2. 主视觉层
- **左侧/中心**：古代哲学家剪影（如孔子、老子侧脸轮廓）
- **右侧/下方**：现代儿童剪影（如小女孩仰望星空）
- 形成"古今对话"的视觉隐喻

#### 3. 文字层
- **主标题**：和古人一起想问题
  - 字体：书法风格或圆润手写体
  - 颜色：金色或暖白色
  - 位置：显眼位置，可居中或左对齐
- **副标题**：儿童版中国哲学探险手册
  - 字体：简洁现代
  - 颜色：白色或浅金色
- **品牌标识**：可选，如小星星图标

## 封面文案示例

### 短版（用于小封面）
```
和古人一起想问题
儿童哲学探险
```

### 长版（用于节目描述）
```
穿越时空，和古代大思想家一起想问题！
认识老子、孔子、庄子、王阳明...
用故事和比喻，把深奥的哲学变成好玩的冒险！

适合8-12岁儿童及家长
```

## 配色方案

### 推荐色板
| 颜色名称 | 色值 | 用途 |
|----------|------|------|
| 深空蓝 | #1a237e | 背景主色 |
| 星空紫 | #311b92 | 渐变过渡 |
| 金色 | #ffd54f | 标题、重点 |
| 暖白色 | #fff8e1 | 文字 |
| 星光白 | #e3f2fd | 高光点缀 |

### 禁止使用
- 过于鲜艳的霓虹色
- 刺眼的纯白色背景
- 低质量的卡通剪影
