# 东西方圣贤跨时空对话抖音账号运营计划
## 1. 核心目标
### 目标概述
打造一个抖音短视频自媒体账号，通过轻松幽默的跨时空对话形式，让东西方古圣先贤（如孔子、苏格拉底、老子、柏拉图等）就现代人身心灵问题（如焦虑、内耗、迷茫、压力等）展开对话，用经典智慧提供“古方新解”，实现知识传播与心灵疗愈的双重价值。

### 背景与动机
- 现代人普遍面临身心压力与存在困惑，急需既有深度又易于接受的疗愈内容。
- 抖音平台用户基数大、传播力强，适合轻量、有趣的知识内容。
- 通过动画/真人+动画的形式降低制作门槛，保持周更节奏以建立用户期待。
- 长期目标：建立垂直领域影响力，探索知识IP变现可能性。

## 2. 要求与标准
- 产出要求：
  - 《账号定位分析报告》：包含3个账号名称备选、3版简介文案、差异化定位建议，交付时间：计划激活后立即执行。
  - 视觉资产：头像、背景图/Banner各一套，符合古风卡通与现代UI融合风格，交付时间：竞品调研完成后。
  - 样稿试写：1篇完整短视频脚本（含对话文案、场景描述、视觉提示），展示轻松幽默且富有智慧的风格，交付时间：视觉资产设计完成后。
  - 《首周选题策划表》：策划首周（3-5个）具体选题，每个选题包含主题、圣贤组合、核心观点、目标受众痛点，交付时间：样稿确认后。
  - 每周漫画素材：生成有故事情节和对话的多张漫画图片（9:16比例），严格遵循角色形象设定、服装和画面整体风格一致性，交付时间：剧本确认后。
  - 每周视频内容：每周制作并发布1期短视频（15-60秒），基于漫画素材和参考图片合成，严格遵循已确认的风格与选题方向，交付时间：每周固定时间（如每周五18:00）。
- 风格偏好：
  - 语气：轻松幽默但不低俗，对话自然有梗，避免说教感。
  - 视觉：古风卡通角色设计，场景可穿越（如古代书房与现代办公室结合），配色清新明亮。人物形象需严格按照用户提供的参考图片（share_1774405448231.jpeg、1774405406169.png、1774405403572.png、share_1774405306187.jpeg、1774405401579.png、IMG_20260325_101055_edit_328889354840422.jpg、R1_refined.png.jpg、R2_new.png.jpg、R3_refined.png.jpg）执行，确保角色形象一致性。孔子特征：花白头发、深蓝色发带束发髻、灰白长胡须、米白色宽袖汉服带深蓝色镶边；庄子特征：灰白长发、简单发髻、灰蓝色短袖交领汉服、深色长裤、慵懒姿态；现代职场人特征：深棕色短发、浅蓝色西装外套、白色衬衫、浅灰色领带，神情略带窘迫。图片比例9:16。
  - 内容深度：每个视频围绕一个具体身心灵议题，在幽默中传递圣贤核心智慧，确保有可回味的思想价值。
  - 聚焦方向：当前阶段优先聚焦孔子与庄子组合的对话主题，其他圣贤组合可作为备选或后续扩展。
  - 配音语调：老子需沉稳缓慢，富有哲思感；伊壁鸠鲁需诙谐轻快，带点玩世不恭的智慧感；其他圣贤角色根据其历史形象与对话主题调整。
- 文件目录规则：
  - 核心交付资产：`outputs/`（存放最终报告、视觉资产、视频脚本、数据复盘等）
  - 过程数据与缓存：`temp/`（存放中间素材、调研原始数据等）
  - 逻辑脚本与工具：`scripts/`（存放自动化脚本、工具函数等）
- 数据依赖：
  - 需通过搜索工具获取抖音平台同类账号的竞品信息。
  - 需使用文生图技能生成视觉资产。
  - 需参考 self-media-planner 技能中的抖音平台指南（references/douyin-platform.md）了解平台规则与爆款特征。
- 通知规则：
  - 每个事项（竞品调研、视觉设计、样稿、选题策划）完成后，推送通知并附上交付物链接。
  - 每周视频发布后，推送发布成功通知。

## 3. 经验沉淀
- **粒度控制**：热点挖掘任务容易因搜索结果内容过多导致上下文超限。应采用分阶段执行策略：第一阶段完成搜索和初步识别，第二阶段基于中间文件进行筛选和表格整理。当任务因上下文超限部分完成时，需立即创建延续事项完成剩余工作。
- **文件路径**：热点挖掘的完整结果应保存到 `outputs/热点挖掘/{日期}.md`，中间过程文件可保存在 `temp/` 目录下。

## 4. 执行路线图
### 第一阶段：初始化（Day 0）
- [✓] 竞品调研与定位分析：搜索抖音平台“哲学对话”“心灵疗愈”“知识动画”类账号3-5个，分析其选题、视觉、互动特点，输出《账号定位分析报告》。
- [✓] 视觉资产设计：根据定位报告，生成头像和背景图/Banner各一套，要求古风卡通风格，融入现代元素，体现“跨时空对话”主题。
- [✓] 样稿试写与风格确认：撰写1期完整短视频脚本，主题例如“孔子与苏格拉底聊职场内耗”，展示对话节奏、幽默梗植入与智慧点。
- [✓] 选题库建设：结合热点与定位，策划首周3-5个具体选题，输出《首周选题策划表》。

### 第二阶段：日常运行（Week 1）
- [ ] 每日热点挖掘：每天搜索当日身心灵相关热点/话题，直接筛选高价值选题填入《选题策略表》。
- [ ] 剧本创作（每周一次）：基于热点挖掘报告确定选题，撰写包含对话、场景和动作的短剧剧本。
- [ ] 漫画生成（每周一次）：根据剧本生成多张连贯的漫画图片（9:16比例），包含对话气泡，严格遵循角色形象设定、服装和画面整体风格一致性。
- [ ] 视频合成（每周一次）：基于漫画图片和参考图片合成短剧视频，确保音画同步和转场自然。
- [ ] 视频发布（每周一次）：检查合成后的视频，添加合适标签，执行发布或预约发布。
- [ ] 周复盘（Week 1结束）：分析首周视频的播放、点赞、评论等数据，评估选题与风格效果，输出《周复盘报告》并策划下周选题。

### 第三阶段：复盘与优化（持续循环）
- [ ] 每周复盘：每周末复盘数据与执行流程，调整下周选题方向。
- [ ] 每周规划：基于复盘结果，策划下周3-5个选题，更新《下周选题策划表》。
- [ ] 每周执行：按更新节奏持续创作、发布，保持账号活跃度与内容质量。
