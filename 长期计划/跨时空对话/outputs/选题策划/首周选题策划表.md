# 首周选题策划表

## 背景说明
基于「圣贤疗愈所」账号定位：东西方古圣先贤跨时空对话，用轻松幽默的现代梗为现代人的焦虑、内耗、迷茫等身心灵问题提供“古方新解”。首周选题需紧扣近期身心灵热点，延续样稿（孔子 vs 苏格拉底）的幽默疗愈风格，确保每期视频既有思想深度又易于传播。

## 近期热点关键词（2026年3月）
- **疗愈经济**：年轻人“花钱买状态”，情绪价值成为消费新引擎
- **新平衡主义**：在忙与闲、自我与外界间寻找可控的“刚刚好”
- **封印解除/元神归位**：告别内耗、找回真实自我的成长热词
- **允许一切发生**：接纳不完美，与生活温柔和解的治愈心态
- **情绪自主**：从“控制情绪”到“情绪自主”的科学管理趋势
- **存在主义危机**：对人生意义、目的的普遍性质疑

## 选题设计思路

### 1. 老子 vs 伊壁鸠鲁：欲望管理
- **热点连接**：疗愈经济中“花钱买开心”现象的反向思考
- **幽默点**：老子说“少私寡欲”，伊壁鸠鲁说“快乐就是身体无痛苦、灵魂无纷扰”，两人一起吐槽现代人“用购物车填满内心空洞”
- **视觉梗**：两人面前堆满快递箱，拆开后全是“空气”（寓意空虚消费）

### 2. 庄子 vs 尼采：存在主义焦虑
- **热点连接**：Z世代普遍存在的“意义感缺失”与“存在主义危机”
- **幽默点**：庄子用“蝴蝶梦”讲相对主义，尼采用“永恒轮回”讲创造价值，两人比赛谁更能“解构又重建”
- **视觉梗**：背景在“虚无”与“意义”之间切换，两人像打乒乓球一样把“人生意义”打来打去

### 3. 王阳明 vs 苏格拉底：内耗与行动力
- **热点连接**：职场内耗、完美主义导致的行动瘫痪
- **幽默点**：王阳明说“知行合一”，苏格拉底说“未经审视的生活不值得过”，两人一起给“只想不干”的现代人开药方
- **视觉梗**：两人用“心学之剑”和“哲学之镜”砍碎“拖延怪兽”

### 4. 佛陀 vs 塞涅卡：情绪控制
- **热点连接**：情绪自主、正念减压的科学趋势
- **幽默点**：佛陀教“观呼吸”，塞涅卡教“区分可控与不可控”，两人一起帮现代人从“情绪过山车”上下来
- **视觉梗**：情绪像彩色气球，两人用“正念线”和“理性剪刀”温柔管理

### 5. 墨子 vs 康德：人际关系边界
- **热点连接**：情绪价值变现、边界感成为现代社交刚需
- **幽默点**：墨子讲“兼爱”但反对“无差别牺牲”，康德讲“义务”但强调“理性边界”，两人一起教“讨好型人格”说“不”
- **视觉梗**：两人在人际关系“地图”上画清晰的“国界线”

## 执行建议

### 内容创作要点
1. **对话节奏**：保持快节奏问答，每句不超过15字，避免说教
2. **梗密度**：每10秒至少1个古今碰撞的幽默梗
3. **智慧点睛**：结尾必须有1-2句可截图传播的金句
4. **视觉提示**：每个选题需设计2-3个标志性视觉元素（如图标、动画、文字特效）

### 制作排期（参考）
- **周日**：完成所有5期脚本初稿
- **周一**：脚本定稿，开始第一期动画制作
- **周二~周五**：每日制作并发布一期
- **周六**：数据复盘，收集用户反馈，策划下周选题

### 互动设计模板
每期视频结尾统一使用：
```
【圣贤云诊室·下周门诊预告】
· 下期圣贤：______
· 诊治病症：______
· 挂号方式：评论区留下你的困惑
```
置顶评论引导用户参与互动，增加黏性。

## 预期效果
- **知识传播**：每期提供一个可操作的身心灵问题解决框架
- **情绪共鸣**：通过幽默对话缓解用户焦虑，产生“被理解”感
- **社交传播**：金句截图、古今碰撞的趣味性促进二次传播
- **账号成长**：首周高频更新快速建立用户期待与关注习惯
