# 视频制作工作流 - 分段生成方案

## 一、整体策略

### 核心思路
- **分段生成**：每10秒生成一段视频
- **统一风格**：使用固定的提示词模板，保持连贯性
- **最终合成**：18段视频合成为3分钟完整视频

### 技术参数
- 单段时长：10秒
- 总段数：18段
- 总时长：180秒（3分钟）
- 分辨率：1080p
- 帧率：30fps

## 四、制作流程

### 步骤1：逐段生成
1. 按顺序调用视频生成工具
2. 每段生成10秒视频
3. 保存为 `segment_01.mp4` ~ `segment_18.mp4`

### 步骤2：质量检查
1. 检查每段视频是否有动态内容
2. 确认人物形象一致性
3. 确认风格统一

### 步骤3：视频合成
1. 使用ffmpeg拼接所有片段
2. 添加背景音乐（古风轻音乐）
3. 添加字幕（对话内容）
4. 输出最终视频

## 五、合成命令

```bash
# 创建片段列表文件
cat > segment_list.txt << EOF
file 'segment_01.mp4'
file 'segment_02.mp4'
file 'segment_03.mp4'
...
file 'segment_18.mp4'
EOF

# 拼接视频
ffmpeg -f concat -i segment_list.txt -c copy 第1集_完整版.mp4

# 添加音频
ffmpeg -i 第1集_完整版.mp4 -i background_music.mp3 -c:v copy -c:a aac 第1集_最终版.mp4
```

## 六、质量保障

### 连贯性检查清单
- [ ] 所有片段中小星形象一致（粉色衣服、马尾）
- [ ] 所有片段中小宇形象一致（蓝色衣服、眼镜）
- [ ] 所有片段中老子形象一致（白胡子、青牛）
- [ ] 场景风格统一（天台夜景、星空）
- [ ] 镜头转换流畅

### 应急预案
- 如果某段生成失败，重新生成该段
- 如果风格不统一，调整提示词重新生成
- 如果时长不准，用ffmpeg调整速度
