## 角色说明

### 小星（10岁女孩）
- **性格**：活泼好奇，爱问"为什么"，想象力丰富
- **台词特点**：疑问句、感叹句、跳跃性比喻
- **口头禅**："为什么呀？""我懂了！""就像……一样！"
- **动作**：思考时歪头，兴奋时跳起，不解时皱眉嘟嘴

### 小宇（11岁男孩）
- **性格**：理性思考，喜欢编程，逻辑清晰
- **台词特点**：陈述句、反问句、科学视角
- **口头禅**："从逻辑上讲……""等等，这有问题""用程序来类比的话……"
- **动作**：思考时推眼镜，怀疑时眯眼，理解时点头

### 老子（圣哲）
- **出场方式**：光影特效，神秘感
- **教学风格**：苏格拉底式启发，用比喻引导
- **语气**：平和、微笑点头

## 下一步制作建议

### 视频风格参考
- **画面风格**：清新插画风，类似《如果历史是一群喵》
- **色彩基调**：老子系列以青绿色为主，体现"道"的自然感
- **动效**：光影流转、柔和渐变

### 配乐建议
- 老子出场：古琴/笛声，神秘悠远
- 对话部分：轻柔钢琴/弦乐
- 顿悟时刻：清脆音效
- 片尾：温暖渐弱

### 制作注意事项
1. 保持小星、小宇声音的辨识度
2. 老子声音要有沧桑感但不失温和
3. 每集片尾的"预告"要形成悬念
4. 比喻要配合画面动画呈现
