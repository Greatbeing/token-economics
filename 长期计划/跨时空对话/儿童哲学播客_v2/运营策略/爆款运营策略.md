## 二、封面设计规范

### 设计原则
1. **儿童友好**：色彩鲜艳，视觉温暖
2. **视觉冲击力**：一眼抓住注意力
3. **信息清晰**：节目名、系列名一目了然
4. **品牌统一**：形成系列感

### 封面模板
```
┌─────────────────────────────────────┐
│  [圣哲人物剪影/卡通形象]            │
│                                      │
│  《给孩子的中国哲学课》              │
│  ——和圣哲一起思考                    │
│                                      │
│  第X集：集标题                        │
│  [适合年龄标签]                      │
└─────────────────────────────────────┘
```

### 色彩方案
| 章节主题 | 主色调 | 辅助色 | 圣哲代表色 |
|---------|-------|-------|-----------|
| 世界与人生 | 宇宙蓝 | 星光金 | 老子-青色 |
| 智慧策略 | 智慧紫 | 策略橙 | 庄子-绿色 |
| 心灵成长 | 心灵粉 | 平静白 | 王阳明-暖黄 |
| 现代智慧 | 现代灰 | 活力红 | 综合-多彩 |

### 封面元素
- **主视觉**：卡通化圣哲人物（如：骑青牛的老子、持羽扇的孟子）
- **背景**：星空/云朵/山水等国风元素
- **图标**：年龄标签（8-14岁）、时长标签（10分钟）
- **品牌Logo**：统一放置右下角

## 三、标题优化策略

### 标题公式
```
痛点型：[孩子痛点]怎么办？[圣哲]告诉你答案
好奇型：[惊人发现]原来[日常现象]背后藏着[哲学道理]
对比型：[普遍误解]vs[正确理解]-[圣哲]怎么说？
故事型：[简短故事]中的大智慧
互动型：你知道吗？[圣哲]早就想明白了这个问题
```

### 各集标题示例

#### 第1集：盘古开天
- **痛点型**：孩子问"世界从哪来"怎么回答？
- **好奇型**：一个巨人睡了一万八千年，醒来后把天地劈开了！
- **故事型**：盘古开天地——身体变万物的神话故事

#### 第4集：孟子的人性本善
- **对比型**：人性本善还是本恶？孟子说有四颗种子
- **好奇型**：为什么你看到小猫受伤会心疼？孟子说是心里有颗善种子
- **互动型**：你的"善种子"发芽了吗？

#### 第7集：庄子的逍遥游
- **好奇型**：一只大鹏能飞九万里，一只麻雀只能飞树梢，谁更自由？
- **故事型**：庄子做梦变成蝴蝶——什么叫真正的逍遥？
- **对比型**：追求第一名vs享受过程，庄子选择哪一个？

#### 第10集：老子的无为
- **痛点型**：孩子太焦虑总想"卷"怎么办？
- **好奇型**：什么都不做反而什么都做了？老子的神奇智慧
- **故事型**：骑青牛的老子——不按快进键的园丁

### 标题禁忌
- ❌ 过度标题党
- ❌ 晦涩难懂
- ❌ 与内容不符
- ❌ 涉及敏感话题

## 四、开头钩子设计（黄金3秒）

### 钩子类型
| 类型 | 示例 | 时长 | 适用场景 |
|------|------|------|---------|
| **提问式** | "你知道世界是从哪里来的吗？" | 2秒 | 好奇心激发 |
| **故事式** | "很久很久以前，在一个混沌的大鸡蛋里..." | 3秒 | 故事引入 |
| **惊讶式** | "两千五百年前，有一个骑牛的老爷爷..." | 2秒 | 吸引注意 |
| **对比式** | "你觉得赢很重要？但庄子说..." | 2秒 | 制造反差 |
| **问题式** | "如果有一天，你和古圣先贤对话..." | 2秒 | 场景设定 |

### 标准开头模板
```
[背景音：轻柔的中国风音乐起]

小星：Hey小宇，你有没有想过一个问题？
小宇：什么问题？
小星：世界...是从哪里来的？
小宇：哦？又是你的"十万个为什么"时间到了？
小星：这次不一样！今晚，我们请到了一位特别的客人...
[音效：风铃声]
小星：欢迎...老子爷爷！
```

### 每集开头元素（10秒内必须出现）
1. **问候语**："小朋友们好，欢迎收听..."
2. **集数介绍**："今天我们来聊第X集..."
3. **内容预告**："我们今天要探索..."
4. **趣味钩子**：与内容相关的趣味问题或故事

## 五、互动设计

### 每集固定互动环节
```
[时间点：第8-9分钟]

小星：好啦，今天的哲学时间快结束了。
小宇：但别急着走！我们给你留了一个小任务。
小星：[说出思考题]
小宇：[补充说明]
小星：欢迎在评论区分享你的想法，我们会认真看哦！
小宇：也可以加入我们的学习社群，每天打卡交流。
小星：下一集，我们继续和圣哲一起思考！
```

### 互动类型
| 互动类型 | 形式 | 时长 | 目的 |
|---------|------|------|------|
| 思考题 | 开放式问题 | 30秒 | 深度思考 |
| 实践任务 | 具体可操作 | 30秒 | 学以致用 |
| 打卡任务 | 每日坚持 | 20秒 | 培养习惯 |
| 投票选择 | 选择题 | 20秒 | 了解想法 |
| 故事续写 | 创意写作 | 30秒 | 激发想象 |

### 思考题设计原则
1. **开放性**：没有标准答案
2. **贴近生活**：与孩子日常相关
3. **有深度**：能引发持续思考
4. **可分享**：愿意在评论区表达

### 思考题示例
```
第1集思考题：
"如果你是盘古，你会用什么方式创造世界？"
（没有对错，鼓励创意和分享）

第7集思考题：
"什么时候你觉得即使没赢也很快乐？"
（联系个人经历，引发共鸣）
```

## 八、数据分析指标

### 核心指标
| 指标 | 目标值 | 监测频率 |
|------|-------|---------|
| 播放量 | 单集10万+ | 每日 |
| 完播率 | 60%+ | 每周 |
| 互动率 | 5%+ | 每日 |
| 收藏率 | 3%+ | 每周 |
| 转发率 | 2%+ | 每日 |

### 优化策略
1. **播放量低**：优化标题/封面/开头
2. **完播率低**：精简内容/增加互动
3. **互动率低**：优化思考题/加强社群运营
4. **收藏率低**：增加实用价值/降低门槛
