# 角色设定详解

## 一、主角设定

### 小星（Xiao Xing）

#### 基本信息
- **全名**：李小星
- **年龄**：10岁（小学四年级）
- **生日**：春天（白羊座）
- **性格关键词**：活泼、好奇、想象力丰富、感性、善良

#### 外貌特征
- **发型**：高马尾，刘海微卷
- **发色**：深棕色
- **眼睛**：圆溜溜的大眼睛，浅棕色
- **脸型**：圆脸，脸颊有淡淡的粉色
- **身高**：1.35米
- **体型**：瘦小活泼

#### 服装设计
- **日常装**：
  - 粉色T恤（有星星图案）
  - 蓝色牛仔短裤
  - 白色运动鞋
  - 手腕上有星星手链
- **季节变化**：
  - 春：粉色卫衣 + 牛仔裤
  - 夏：粉色T恤 + 短裤
  - 秋：粉色毛衣 + 长裤
  - 冬：粉色羽绒服 + 围巾

#### 性格特点
- **好奇心强**：对一切事物都充满疑问，"为什么"是口头禅
- **想象力丰富**：能快速理解抽象概念，善于用比喻
- **感情丰富**：容易被故事感动，有同理心
- **行动力强**：想到就去做，有时有点冲动
- **善于表达**：喜欢分享自己的想法

#### 语言特点
- **常用语气**：疑问句、感叹句多
- **口头禅**：
  - "为什么呀？"
  - "我懂了！"
  - "可是……"
  - "就像……一样！"
- **说话方式**：语速快，语调活泼，喜欢用手势

#### 行为习惯
- 思考时会歪头
- 兴奋时会跳起来
- 不解时会皱眉嘟嘴
- 开心时会拍手
- 专注时会咬笔头

#### 兴趣爱好
- 画画（喜欢画星星和幻想世界）
- 读童话故事
- 观察大自然
- 和朋友聊天

#### 与小宇的关系
- 互补型朋友
- 小星负责提问，小宇负责分析
- 经常一起讨论问题
- 小星有时觉得小宇太较真，小宇有时觉得小星太天真

### 小宇（Xiao Yu）

#### 基本信息
- **全名**：张小宇
- **年龄**：11岁（小学五年级）
- **生日**：秋天（处女座）
- **性格关键词**：理性、逻辑、好奇心、认真、善良

#### 外貌特征
- **发型**：利落的短发
- **发色**：黑色
- **眼睛**：细长的眼睛，黑色（戴黑框眼镜）
- **脸型**：瓜子脸
- **身高**：1.42米
- **体型**：中等偏瘦

#### 服装设计
- **日常装**：
  - 蓝色T恤（简约款）
  - 深色牛仔裤
  - 黑色运动鞋
  - 黑框眼镜
- **季节变化**：
  - 春：蓝色卫衣 + 牛仔裤
  - 夏：蓝色T恤 + 短裤
  - 秋：蓝色毛衣 + 长裤
  - 冬：蓝色外套 + 围巾

#### 性格特点
- **理性思考**：喜欢用逻辑分析问题
- **好奇心强**：对科学和编程感兴趣
- **认真负责**：做事有条理，追求完美
- **批判性思维**：善于发现逻辑漏洞
- **内心善良**：虽然理性，但很有爱心

#### 语言特点
- **常用语气**：陈述句、反问句多
- **口头禅**：
  - "从逻辑上讲……"
  - "等等，这有问题"
  - "用程序来类比的话……"
  - "这不符合……"
- **说话方式**：语速中等，语调平稳，喜欢推眼镜

#### 行为习惯
- 思考时会推眼镜
- 怀疑时会眯眼
- 理解时会点头
- 兴奋时会握拳
- 困惑时会挠头

#### 兴趣爱好
- 编程（Scratch、Python）
- 科学实验
- 读科普书
- 下棋

#### 与小星的关系
- 互补型朋友
- 小宇负责分析，小星负责感受
- 经常一起讨论问题
- 小宇保护小星，小星温暖小宇

## 二、圣哲形象设计

### 老子

#### 形象特征
- **年龄**：老年（白胡子）
- **身高**：中等偏高
- **服装**：青色道袍，头巾
- **标志性元素**：
  - 骑青牛
  - 白色长胡子
  - 手持竹简
  - 神秘温和的笑容

#### 性格特点
- 神秘、温和、智慧
- 说话缓慢，带有哲理
- 喜欢用比喻和谜语

#### 出场方式
- 光影闪烁，骑青牛从云雾中出现
- 常出现在自然场景（山、水、星空）

## 五、角色一致性要求

### 小星的台词风格
1. 多用疑问句："为什么……？"、"怎么会这样？"
2. 多用比喻："就像……一样！"
3. 情感丰富："好神奇！"、"我不明白……"
4. 行动导向："我们去找答案吧！"

### 小宇的台词风格
1. 多用陈述句："从逻辑上讲……"
2. 多用质疑："等等，这有问题……"
3. 科学视角："用科学来说……"
4. 类比思维："用程序来类比的话……"

### 圣哲的台词风格
1. 引用经典："古人说……"
2. 循循善诱："你想想看……"
3. 用比喻说明："就像……"
4. 留下思考："回去想想……"
