# 《给孩子的中国哲学课》视频节目策划书

## 一、节目定位

### 基本信息
- **节目名称**：给孩子的中国哲学课——和圣哲一起思考
- **节目类型**：儿童哲学启蒙动画视频
- **目标观众**：8-14岁儿童及其家长
- **总集数**：72集
- **每集时长**：3分钟
- **播出平台**：抖音、快手、视频号、B站、YouTube

### 核心特色
- **双主角设定**：小星（10岁女孩，活泼好奇）+ 小宇（11岁男孩，理性思考）
- **古今对话**：现代儿童与古代圣哲的跨时空交流
- **生活化场景**：从日常问题切入，用孩子能懂的方式讲哲学
- **视觉风格**：清新可爱萌系动画，国风与现代元素融合

## 二、角色设定

### 主角一：小星
- **年龄**：10岁
- **性格**：活泼好奇，爱问"为什么"，富有想象力，感情丰富
- **外貌**：扎马尾，大眼睛，穿着鲜艳可爱的休闲装
- **口头禅**："为什么呀？""我懂了！""可是……"
- **特长**：善于提问，能用比喻理解抽象概念
- **视觉特征**：粉色系服装，马尾辫，活泼的肢体语言

### 主角二：小宇
- **年龄**：11岁
- **性格**：理性思考，喜欢编程，逻辑清晰，偶尔有点较真
- **外貌**：戴眼镜，短发，穿着简约的T恤和牛仔裤
- **口头禅**："从逻辑上讲……""等等，这有问题""用程序来类比的话……"
- **特长**：善于分析，能发现逻辑漏洞，喜欢用科学视角思考
- **视觉特征**：蓝色系服装，黑框眼镜，思考时推眼镜的动作

## 四、视频脚本模板

### 3分钟脚本结构

```
【片头】（5秒）
- 节目logo + 主标题动画
- "给孩子的中国哲学课"

【开场】（15秒）
- 场景：日常生活场景（学校、家、公园等）
- 小星提出问题或遇到困惑
- 小宇尝试用逻辑分析

【圣哲出场】（10秒）
- 古代圣哲神奇出现（光影特效）
- 自我介绍 + 引入主题

【核心对话】（120秒 = 2分钟）
- 小星/小宇提问 → 圣哲解答
- 用比喻和例子说明抽象概念
- 小宇质疑/验证 → 圣哲进一步解释
- 小星感悟 → 生活化应用

【互动环节】（20秒）
- 圣哲布置思考任务
- 小星/小宇分享感悟
- 引导观众思考

【片尾】（10秒）
- 本集金句
- 下集预告
- 互动引导（点赞/关注/评论）
```

### 脚本示例（第1集：星星从哪儿来的？）

```
【片头】5秒
（动画：书页翻动，出现节目logo）

【开场】15秒
（场景：小区天台，夜晚）
小星：（指着星星）小宇，你说这些星星是从哪儿来的？
小宇：（推眼镜）科学老师说，宇宙是从大爆炸开始的。但大爆炸之前呢？

【圣哲出场】10秒
（光影闪烁，老子骑青牛出现）
老子：你们的问题，两千五百年前也有人问过。

【核心对话】120秒
小星：老爷爷，您知道答案吗？
老子：（微笑）我知道，但语言说不清。我给你们一个线索——"道"。
小宇：等等，怎么证明"道"是真的？
老子：问得好！这正是哲学的开始——先质疑，再思考。
（继续对话，用秋千、游戏等比喻解释"道"）

【互动环节】20秒
老子：今晚回去，观察一个自然现象，想想它背后有什么规律？
小星：我观察月亮！
小宇：我观察影子！

【片尾】10秒
金句："道可道，非常道。"——老子
下集预告：盘古如何开天辟地？
互动：你喜欢看星星吗？在评论区告诉我！
```

## 五、视觉风格

### 动画风格
- **类型**：2D扁平动画 + 少量3D场景
- **配色**：莫兰迪色系（淡蓝、淡粉、淡黄、淡绿）
- **人物设计**：Q版可爱风格，线条简洁
- **场景设计**：现代简约 + 国风点缀

### 分镜要求
- 每集约180个镜头
- 平均每个镜头1秒
- 关键对话镜头停留2-3秒

### 视觉元素
- **转场**：书页翻动、星光闪烁、云雾飘散
- **特效**：圣哲出场时光晕、对话时思维气泡、感悟时星光闪耀
- **字幕**：大字清晰，关键词高亮
