# 图片管理系统优化报告

## 问题分析

在批量生成HTML样张过程中，发现以下问题：

1. **标题结构不匹配**：章节实际标题与映射表中的标准位置标签不一致
   - 第六章：使用“第一营区”、“第二营区”、“第三营区”而非“第一站”、“第二站”、“第三站”
   - 第八章：缺少“第二站”标题，使用“禅宗故事时间”替代
   - 第十一章：使用“第一课时”、“第二课时”、“第三课时”而非“第一站”、“第二站”、“第三站”

2. **匹配逻辑过于严格**：原脚本使用`line.startswith(target_title)`进行精确匹配，无法处理标题变体

## 解决方案

### 1. 实现灵活标题匹配函数

在`src/generate_chapter_html.py`中创建`match_title_line()`函数，支持：

- **完全匹配**：标题文本与目标文本完全一致
- **关键词匹配**：对于“思想剧场”、“想一想”、“全球望远镜”、“实践练习”、“古人说”、“禅宗故事时间”等特殊标题，检查标题中是否包含关键词
- **数字站点变体匹配**：对于“第一站”、“第二站”、“第三站”等数字站点标题，支持变体（“站”、“营区”、“课时”）
- **通用前缀匹配**：对于其他标题，检查标题文本是否以目标文本开头

### 2. 实现章节特定标题映射

在`insert_images_into_markdown()`函数中添加章节特定映射机制，覆盖通用映射：

```python
chapter_specific_titles = {
    8: {
        "after_second_station": "## 禅宗故事时间",
    }
}
```

### 3. 优化图片插入流程

- 优先使用章节特定映射
- 增强错误提示，明确显示未匹配的标题
- 保持原有的Data URI图片嵌入方式
