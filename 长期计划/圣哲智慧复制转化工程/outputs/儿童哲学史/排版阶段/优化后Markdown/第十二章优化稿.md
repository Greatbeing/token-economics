# 第十二章：我们为什么要学哲学？——探险家的毕业典礼与终身邀请

#<div class="thought-theater">
## 思想剧场：哲学探险家毕业典礼

<div class="dialog-line">
<span class="dialog-role">时间</span>：初夏午后
</div>

<div class="dialog-line">
<span class="dialog-role">地点</span>：校园小花园，12张长椅围成半圆
</div>

<div class="dialog-line">
<span class="dialog-role">人物</span>：哲学俱乐部全体成员（小智、小慧、小美、小强等12人），以及从书中走出的三位特别嘉宾
</div>

**场景**：

12个孩子每人手里拿着一个精致的木盒，里面装着12个月来收集的“智慧探险地图碎片”。今天，他们要完成最后一块碎片的拼图，举办一场特别的“哲学探险家毕业典礼”。

<div class="dialog-line">
<span class="dialog-role">小智</span>：（打开木盒）从“世界从哪里来”到“如何当现代中国人”，12个大问题，12位哲人朋友...我好像走了2500年。
</div>

<div class="dialog-line">
<span class="dialog-role">小慧</span>：但奇怪的是，我的问题不仅没减少，反而变多了。原来我以为哲学是“找答案”，现在发现是“学会问更好的问题”。
</div>

<div class="dialog-line">
<span class="dialog-role">小美</span>：这就是哲学最神奇的地方——它不给你终点，只给你一双更敏锐的眼睛。
</div>

**突然，花园入口处传来三个声音——**

**梁启超**（1873-1929，穿中山装，目光炯炯）：孩子们，听说你们要“毕业”？在哲学里，毕业只是另一个开始。

**冯友兰**（1895-1990，戴眼镜，儒雅温和）：我花了半辈子把中国哲学翻译给世界看，现在轮到你们把哲学“翻译”进自己的生活了。

**熊十力**（1885-1968，长衫飘飘，手拿烟斗）：毕业？哲学是终身的健身房，你们才刚做完热身运动呢！

<div class="dialog-line">
<span class="dialog-role">小强</span>：（惊讶）三位先生，你们...都是近代的思想家？为什么一起来参加我们的毕业典礼？
</div>

<div class="dialog-line">
<span class="dialog-role">梁启超</span>：因为我们三个，正好代表了“为什么学哲学”的三个核心理由——改变社会、理解世界、修炼生命。而你们这12个月的探险，已经不知不觉踏上了这三条路。
</div>

<div class="dialog-line">
<span class="dialog-role">小慧</span>：（举手提问）梁先生，您说“改变社会”——哲学真的能改变社会吗？我觉得哲学好像都是在书斋里思考...
</div>

<div class="dialog-line">
<span class="dialog-role">梁启超</span>：（微笑）好问题！这是我今天的第一个🌟**新民**任务——告诉你哲学如何从书斋走向街头。但首先，让我们正式开启这场“毕业对话”。
</div>
