# 《儿童版中国哲学史》PDF电子书修正说明

## 修正概述
基于用户反馈，针对《儿童版中国哲学史》PDF电子书存在的两大核心问题进行系统性修正：

1. **封面问题**：原cover_simple.html不符合A4尺寸PDF封面要求，封面图片未全页面覆盖，书名不够清晰
2. **排版清晰度问题**：对话未分行、段落间距不足、小标题视觉突出不明显

## 一、封面问题修正

### 问题分析
- 原封面使用渐变背景，未使用指定的封面图片
- 图片路径问题导致wkhtmltopdf安全限制下无法加载
- 封面尺寸未严格遵循A4标准（210mm×297mm）
- 书名与副标题对比度不足

### 技术解决方案
1. **Data URI嵌入方案**：将封面图片（`封面设计.jpg`）转换为Base64编码的Data URI格式，直接嵌入HTML，彻底解决文件路径访问问题
2. **A4全页面覆盖**：
   - CSS设置：`width: 210mm; height: 297mm;`
   - 背景图片：`background-size: cover; background-position: center;`
   - 去除页边距：`margin: 0; padding: 0;`
3. **书名清晰呈现**：
   - 半透明白色背景层（`rgba(255,255,255,0.92)`）增强对比度
   - 主标题：56px #FF6B35，加粗，阴影
   - 副标题：42px #1565C0，适中大小
   - 阴影效果：`box-shadow: 0 25px 50px rgba(0,0,0,0.3)`

### 实施步骤
1. 创建Python脚本 `src/generate_cover_with_datauri.py`
2. 读取封面图片（2848×1600 JPEG）
3. 转换为Data URI格式（`data:image/jpeg;base64,...`）
4. 生成包含Data URI背景的HTML文件
5. 使用wkhtmltopdf转换为PDF，确保A4尺寸

### 生成文件
- `cover_final_datauri.html` - Data URI嵌入的封面HTML
- `cover_final.pdf` - 正确的A4尺寸PDF封面

### 验证结果
- 尺寸：595×842 pts（标准A4）
- 文件大小：241 KB
- 图片全页面覆盖，无白边
- 书名与副标题清晰可读

## 二、排版清晰度修正

### 问题分析
1. **对话挤在一起**：不同角色对话未独立成行
2. **段落间距不足**：文字密度过高，阅读压力大
3. **小标题不突出**：章节内部站点标题视觉区分不明显
4. **内嵌CSS冲突**：HTML文件中内嵌对话CSS覆盖外部样式

### 技术解决方案

#### 1. CSS样式增强
修改 `outputs/儿童哲学史/排版阶段/章节HTML/style.css`：

```css
/* 对话样式优化 - 增强版 */
.dialog-line {
    margin-bottom: 24px;                    /* 增加间距 */
    padding: 16px 20px;                     /* 增加内边距 */
    border-left: 5px solid #81D4FA;         /* 加粗左边框 */
    background-color: rgba(129,212,250,0.08); /* 浅蓝色背景 */
    line-height: 1.8;                       /* 增加行高 */
    border-radius: 0 8px 8px 0;             /* 圆角效果 */
    page-break-inside: avoid;               /* 避免跨页断行 */
}

/* 段落间距增强 */
p {
    margin-bottom: 24px !important;         /* 强制增加段落间距 */
    line-height: 1.7;
}

/* 小标题分行增强 */
h3, h4 {
    margin-top: 32px;                       /* 增加上方间距 */
    margin-bottom: 16px;                    /* 增加下方间距 */
    page-break-after: avoid;                /* 避免标题后分页 */
}
```

#### 2. 清理内嵌CSS冲突
- 创建清理脚本 `src/clean_inline_css.py`
- 移除12章修正版HTML文件中的内嵌对话CSS
- 确保使用统一的外部CSS文件

#### 3. 批量PDF转换
- 创建批量处理脚本 `src/batch_html_to_pdf.py`
- 将12章修正版HTML转换为PDF
- 统一A4尺寸（210mm×297mm）
- 边距设置：15mm（上下左右）

### 验证标准

#### 对话分行检查
- 每个角色对话独立成行
- 左侧有5px蓝色边框
- 浅蓝色背景区分
- 行间距≥1.8倍

#### 段落间距检查
- 段落间有明显视觉分隔
- 底部间距≥24px
- 避免文字挤在一起

#### 小标题突出检查
- 章节内部站点标题独立成行
- 标题前后有足够间距
- 避免与正文视觉混淆
