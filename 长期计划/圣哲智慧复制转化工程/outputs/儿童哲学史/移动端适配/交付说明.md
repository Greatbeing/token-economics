## ✅ 任务4（补充）：修复插图问题并生成最终PDF

### 问题排查
用户反馈PDF中插图缺失。经排查发现：
- 清理后的HTML文件（chapters_clean/）中**没有img标签**引用图片
- 优化后的WebP图片（45张）存放在 `optimized_images/` 目录
- 需要将图片以base64编码方式嵌入HTML

### 解决方案
1. 读取清理后的12章HTML文件
2. 在每章末尾添加4张场景图（base64编码嵌入）
3. 重新生成完整HTML（merged_with_images.html）
4. 使用wkhtmltopdf生成最终PDF

### 新增输出
```
最终交付/
└── 和古人一起想问题_移动端优化版.pdf   # 带12章插图 (4.49MB) ⭐⭐
    - 包含45张场景插图
    - A5移动端适配格式
    - base64编码确保PDF显示

移动端适配/chapters_clean/
└── merged_with_images.html            # 带插图的完整HTML (2.08MB)
```

### 排版优化
- 对话独立成行（人物对话使用专属样式）
- 小标题带左侧边框标识
- 段落首行缩进2em
- 引用块灰色背景+蓝色左边框
- 章节插图居中显示
