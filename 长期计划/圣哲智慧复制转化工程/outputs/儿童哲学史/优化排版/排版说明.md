# 第一章专业排版HTML样张 - 排版说明

## 一、设计依据与标准

### 1.1 主要参考标准
1. **中文图书排版规范**（中华人民共和国新闻出版行业标准 CY/T 120-2015）
   - 学术出版规范 - 图书版式
   - 版心基本要求：钉口留白≥20mm，天头、地脚、切口留白≥15mm

2. **中小学教科书版面通用要求**（GB/T 18358）
   - A4尺寸：210×297mm（比例1.414）
   - 字号分级体系（小学高年级使用c类：12pt书宋体为主）

3. **童书排版行业实践**
   - 温暖色调，柔和线条
   - 儿童友好视觉设计
   - 适当增加行距与字体大小

### 1.2 核心排版参数
| 参数项 | 具体数值 | 设计依据 |
|--------|----------|----------|
| **页面尺寸** | 210×297mm (A4) | 标准图书开本 |
| **页边距** | 天头25mm / 地脚20mm / 订口25mm / 切口15mm | 装订安全+视觉平衡 |
| **正文字体** | 宋体（SimSun） | 中文标准衬线字体 |
| **正文字号** | 12pt（小四号） | 小学5-6年级推荐字号 |
| **行距** | 1.5倍 | 提升儿童阅读舒适度 |
| **标题层级** | h1:24pt / h2:18pt / h3:14pt | 清晰视觉层次 |

## 二、样式系统设计

### 2.1 字体方案
- **正文文本**：宋体，12pt，颜色#333（深灰）

## 三、插图嵌入方案

### 3.1 插图配置
第一章包含4张场景插图：
1. **ch1_scene1.jpg** - 位置：思想剧场之后
2. **ch1_scene2.jpg** - 位置：第一站之后
3. **ch1_scene3.jpg** - 位置：第二站之后
4. **ch1_scene4.jpg** - 位置：第三站之后

### 3.2 技术方案
- **嵌入方式**：Data URI Base64编码
- **优点**：确保跨平台显示一致性，避免路径依赖问题
- **文件体积**：HTML文件包含图片数据，总大小约3.2MB（可接受）

### 3.3 插图容器设计
```html
<div class="illustration-container">
    <div class="illustration-title">{插图描述}</div>
    <img src="{data_uri}" alt="{替代文本}" class="chapter-illustration">
    <div class="illustration-caption">{图注}</div>
</div>
```

样式特征：
- 居中对齐
- 标题加粗显示
- 图片圆角阴影
- 图注斜体小字
