# 《儿童版中国哲学史》插图素材库

## 目录说明

本目录存储《儿童版中国哲学史》全书的插图设计素材，为后续插图细化、排版整合及质量检查提供完整资源。

### 1. 分类结构

```
data/illustration_references/
├── 草图源文件/           # 章节场景设计草图（共73个）
├── 地图碎片/             # 智慧探险地图碎片（共12个）
├── 视觉模板/             # 哲学小词卡设计模板（1个）
└── 参考图片/             # 风格参考图片（3张）
```

### 2. 文件清单

#### 2.1 草图源文件
- **数量**：73个场景草图
- **命名规则**：`ch{章节编号}_scene{场景编号}.jpg`
  - 例：`ch1_scene1.jpg`（第一章场景1）
- **涵盖章节**：第1-12章，每章3-5个关键场景
- **主要内容**：哲学对话场景、思想实验情境、古今互动画面
- **用途**：作为插图细化的基础线稿，提供构图、角色、场景参考

#### 2.2 地图碎片
- **数量**：12个地图碎片
- **命名规则**：`map_fragment_ch{章节编号}.jpg`
  - 例：`map_fragment_ch1.jpg`（第一章地图碎片）
- **设计风格**：可拼接藏宝图风格，不规则撕裂边缘
- **视觉要素**：
  - 核心问题图标
  - Q版代表人物剪影
  - 思想工具符号
  - 时间轴指示
- **拼接逻辑**：12个碎片可拼合为完整的中国哲学思想地图

#### 2.3 视觉模板
- **文件**：`philosophy_term_card_template.jpg`
- **规格**：A6卡片大小（105mm × 148mm）
- **布局**：上图为概念视觉化，中为术语名称，下为儿童化定义
- **配色**：根据学派对应色系（儒、道、法、墨等）
- **用途**：生成《哲学小词卡》附录的标准化模板

#### 2.4 参考图片
- **文件**：
  1. `taohuaxi_sample.jpeg` - 《桃花溪》绘本插图（水彩手绘风格）
  2. `philosophy_curiosity.png` - 《哲学的好奇》插图（现代设计风格）
  3. `thinking_charm.jpg` - 《思考的魅力》插图（法式漫画风格）
- **用途**：风格借鉴与灵感参考，确保全书视觉风格符合儿童绘本主流趋势

### 4. 使用流程

#### 4.1 插图细化阶段
1. **参考草图**：打开对应章节的场景草图，了解构图与角色设定
2. **色彩应用**：参照《视觉风格指南》的配色方案
3. **细节深化**：增加哲学符号、背景元素、视觉隐喻
4. **风格统一**：确保与全书其他插图风格一致

#### 4.2 地图使用
1. **单章使用**：每章开篇使用对应的地图碎片
2. **全书拼接**：12个碎片可拼接展示中国哲学全貌
3. **数字互动**：考虑制作可交互的数字地图版本

#### 4.3 小词卡生成
1. **模板应用**：使用`philosophy_term_card_template.jpg`作为基础
2. **术语分类**：根据学派选择对应配色
3. **视觉设计**：为每个术语设计独特的视觉隐喻图形
4. **批量生成**：为全书35个核心术语生成小词卡
