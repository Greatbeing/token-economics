# 圣贤智慧术语降维对照表

## 一、使用说明

### 1.1 目的
本表为“圣贤智慧复刻工程”提供标准化术语降维方案，确保所有内容（尤其是儿童版）中的哲学、思想术语能被12岁孩子理解。

### 1.2 使用规则
1. **强制使用**：创作儿童内容时，必须优先使用“儿童表达”栏中的表述
2. **语境适配**：根据具体语境选择最贴切的儿童表达方案
3. **扩展机制**：遇到新术语时，按本表格式添加并注明添加者、日期
4. **验证要求**：新术语需通过“12岁理解度测试”后方可正式加入

### 1.3 术语分类编码
- **Z**：庄子相关术语
- **K**：孔子相关术语
- **S**：苏格拉底相关术语
- **F**：释迦牟尼（佛陀）相关术语
- **X**：徐霞客相关术语
- **G**：通用哲学术语

## 三、扩展与维护指南

### 3.1 如何添加新术语
1. **发现需求**：在创作过程中遇到难以儿童化表达的术语
2. **头脑风暴**：提出至少2种儿童表达方案，确保符合12岁理解水平
3. **测试验证**：请AI模拟12岁孩子理解，或邀请真实儿童试读
4. **格式规范**：按本表格式添加，注明编码、日期、添加者
5. **分类归档**：根据术语所属圣贤或通用性，放入对应分类

### 3.2 质量检查标准
- **可理解性**：12岁孩子能否在3秒内理解意思？
- **趣味性**：表达是否生动有趣，有画面感？
- **准确性**：是否准确传达了原术语的核心内涵？
- **多样性**：是否提供了至少2种表达方案以适应不同语境？

### 3.3 定期更新机制
- **每周检查**：每完成一位圣贤内容，检查术语库完整性
- **月度复盘**：每月末评估术语使用效果，优化表达方案
- **用户反馈**：收集真实儿童读者的理解障碍，更新对应术语
- **版本管理**：每次重大更新发布新版本（如v1.1、v2.0）

### 3.4 常见问题处理
- **一个术语多种解释**：根据语境选择最贴切的方案，或添加“使用说明”栏注明区别
- **古今含义变化**：以现代通用含义为准，必要时加注“古代特指……”
- **文化差异术语**：注意东西方文化背景，提供文化背景简要说明
- **抽象程度过高**：分级降维：先降到中学生水平，再降到小学生水平
