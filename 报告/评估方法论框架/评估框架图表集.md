## 1. 评估方法论架构图

```mermaid
flowchart TB
    subgraph INPUT["投入层"]
        A1[亚投行贷款资金]
        A2[地方政府配套]
        A3[项目管理资源]
        A4[施工企业资源]
    end

    subgraph PROCESS["方法论处理层"]
        B1[变革理论框架]
        B2[多源三角验证]
        B3[深度案例研究]
        B4[国际对标分析]
        B5[参与式评估]
    end

    subgraph OUTPUT["产出层"]
        C1[量化证据]
        C2[质性证据]
        C3[案例证据]
        C4[比较证据]
    end

    subgraph OUTCOME["评估结论"]
        D1[项目绩效评级]
        D2[经济影响估算]
        D3[经验教训总结]
        D4[政策建议]
    end

    INPUT --> PROCESS
    PROCESS --> OUTPUT
    OUTPUT --> OUTCOME

    style INPUT fill:#e1f5fe
    style PROCESS fill:#fff3e0
    style OUTPUT fill:#e8f5e9
    style OUTCOME fill:#fce4ec
```

## 3. 三角验证模型图

flowchart TB

        subgraph METHODS["验证方法"]
            M1["数据一致性检验"]
            M2["逻辑连贯性分析"]
            M3["交叉比对核实"]
        end

        subgraph RESULT["验证结果"]
            R1["✅ 一致性高\n采纳为强证据"]
            R2["⚠️ 部分验证\n需谨慎解读"]

        D1 --> M1
        D2 --> M2
        D3 --> M3
        M1 --> R1

        M3 --> R3
    end

    style VERIFICATION fill:#fafafa
    style SOURCES fill:#e3f2fd
