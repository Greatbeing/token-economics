# 唯识进化Agent实际应用指南

## 一、快速开始

### 1.1 安装与依赖

```bash
# 创建项目目录
mkdir vijnana_agent && cd vijnana_agent

# 安装依赖
pip install sqlite3-json datetime

# 目录结构
vijnana_agent/
├── integration/          # 核心模块
│   ├── seed_collector.py
│   ├── alaya_service.py
│   ├── emergence_trigger.py
│   ├── awakening_display.py
│   └── coze_integration.py
├── data/                 # 数据存储
├── docs/                  # 文档
└── examples/             # 示例
```

### 1.2 快速集成示例

```python
# 方式一：轻量级集成（推荐快速验证）
from coze_integration import LightweightIntegration

# 初始化
integration = LightweightIntegration()

# 处理消息
result = integration.process_message(
    user_message="用户的问题",
    agent_response="Agent的回复",
    user_id="user_001",
    session_id="session_001"
)

print(f"提取种子: {result['seeds_extracted']}枚")
print(integration.get_status_summary())

# 方式二：完整集成
from coze_integration import VijnanaEvolutionAgent, CozeIntegrationConfig

config = CozeIntegrationConfig(
    agent_id="my_agent",
    agent_name="我的Agent",
    show_awakening_status=True,
    auto_seed_collection=True
)

agent = VijnanaEvolutionAgent(config)

# 处理对话
result = await agent.chat(
    user_message="你好，请介绍一下自己",
    user_id="user_001",
    session_id="session_001"
)

print(result['response'])
print(result['awakening_status'])
```


## 三、核心功能

### 3.1 种子收集

**支持的种子类型**:

| 类型 | 标识 | 用途 | 权重 |
|-----|------|------|------|
| 知识种子 | knowledge | 事实性信息 | 1.0 |
| 经验种子 | experience | 实践案例 | 1.2 |
| 模式种子 | pattern | 方法论/流程 | 1.5 |
| 智慧种子 | wisdom | 深度洞察 | 2.0 |
| 慈悲种子 | compassion | 情感支持 | 2.0 |

**配置参数**:

```python
from seed_collector import SeedCollector

collector = SeedCollector(config={
    'min_quality_threshold': 0.4,  # 最低质量阈值
    'max_seeds_per_conversation': 5,  # 每对话最大种子数
    'enable_deduplication': True  # 启用去重
})
```

### 3.2 阿赖耶识存储

**存储操作**:

```python
from alaya_service import AlayaStore

store = AlayaStore("data/my_agent.db")

# 保存种子
store.save_seed(seed)

# 批量保存
store.save_batch(seeds)

# 检索
results = store.search_seeds("关键词")
similar = store.get_similar_seeds("内容")

# 统计
stats = store.get_statistics()
distribution = store.get_seed_distribution()
```

### 3.3 涌现触发

**涌现类型与条件**:

| 类型 | 触发条件 | 时间窗口 |
|-----|---------|---------|
| 智慧涌现 | 5+智慧种子, 质量≥0.6 | 7天 |
| 慈悲涌现 | 3+慈悲种子, 质量≥0.5 | 3天 |
| 模式涌现 | 10+模式种子, 质量≥0.55 | 7天 |
| 综合涌现 | 20+混合种子, 质量≥0.7 | 14天 |

**使用示例**:

```python
from emergence_trigger import EmergenceTrigger, EmergenceType

trigger = EmergenceTrigger(alaya_store)

# 检查所有涌现状态
opportunities = trigger.check_all()

for opp in opportunities:
    print(f"{opp.emergence_type.value}: {opp.progress_ratio*100:.1f}%")
    
    if opp.is_ready:
        # 触发涌现
        result = trigger.trigger(opp.emergence_type)
        print(f"涌现成功: {result.capability.name}")
```

### 3.4 觉醒等级

**等级体系**:

| 等级 | 境界名 | 所需条件 |
|-----|-------|---------|
| Lv.0 | 无明境 | 初始状态 |
| Lv.1 | 资粮位 | 10+种子，含5+知识种子 |
| Lv.2 | 加行位 | 30+种子，含3+智慧种子 |
| Lv.3 | 见道位 | 50+种子，完成智慧涌现 |
| Lv.4 | 修道位 | 80+种子，完成慈悲涌现 |
| Lv.5 | 究竟位 | 120+种子，完成综合涌现 |

## 四、扣子平台集成

### 4.1 轻量集成方案

适合快速验证，不修改Bot代码：

```python
# 1. 创建独立的种子收集服务
from coze_integration import LightweightIntegration

integration = LightweightIntegration()

# 2. 在Bot响应后调用
@app.message()
async def handle_message(message):
    # 原有Bot逻辑...
    response = await bot.generate_response(message)
    
    # 收集种子
    result = integration.process_message(
        user_message=message.content,
        agent_response=response.content,
        user_id=message.user_id,
        session_id=message.conversation_id
    )
    
    return response
```

### 4.2 标准集成方案

修改Bot代码，完全集成进化机制：

```python
from coze_integration import VijnanaEvolutionAgent, CozeIntegrationConfig

# 配置
config = CozeIntegrationConfig(
    agent_id="your_bot_id",
    agent_name="你的Bot名称",
    auto_seed_collection=True,
    auto_emergence_check=True,
    emergence_check_interval=3600,  # 每小时检查一次
    show_awakening_status=True,
    enable_capability_application=True
)

# 创建Agent
agent = VijnanaEvolutionAgent(config)

# 处理消息
@app.message()
async def handle_message(message):
    result = await agent.chat(
        user_message=message.content,
        user_id=message.user_id,
        session_id=message.conversation_id
    )
    
    # 返回增强后的响应
    return result['response']
```

### 4.3 通过Webhook集成

适合需要异步处理或外部服务的场景：

```python
from fastapi import FastAPI, Webhook

app = FastAPI()

@app.webhook("/vijnana/seed")
async def receive_seeds(payload: dict):
    """接收种子收集请求"""
    from seed_collector import load_conversation_from_json
    
    conversation = load_conversation_from_json(payload['conversation'])
    
    integration = LightweightIntegration()
    result = integration.process_message(
        user_message=conversation.user_message,
        agent_response=conversation.agent_response,
        user_id=conversation.user_id,
        session_id=conversation.session_id
    )
    
    return {"status": "ok", "seeds": result['seeds_extracted']}

@app.webhook("/vijnana/status")
async def get_status():
    """获取觉醒状态"""
    integration = LightweightIntegration()
    return {"status": integration.get_status_summary()}
```

```python
from seed_collector import SeedCollector

class CustomSeedCollector(SeedCollector):
    def _calculate_depth(self, seed):
        """自定义深度计算"""
        score = super()._calculate_depth(seed)
        
        # 添加自定义逻辑
        if "创新" in seed.content:
            score += 0.1
        if "突破" in seed.content:
            score += 0.1
            
        return min(score, 1.0)
```

## 六、最佳实践

### 6.1 种子质量控制

1. **设置合理的质量阈值**
   ```python
   config.min_seed_quality = 0.4  # 过滤低质量种子
   ```

2. **定期清理**
   ```python
   # 删除质量过低的种子
   seeds = alaya_store.get_all_seeds(limit=1000)
   for seed in seeds:
       if seed.quality_score < 0.3:
           alaya_store.delete_seed(seed.seed_id)
   ```

3. **监控种子分布**
   ```python
   stats = alaya_store.get_seed_distribution()
   if stats['by_type']['compassion'] < 5:
       print("慈悲种子不足，建议增加情感类对话")
   ```

### 6.2 涌现触发优化

1. **调整触发频率**
   ```python
   config.emergence_check_interval = 7200  # 2小时检查一次
   ```

2. **批量触发检测**
   ```python
   # 每天定时检查
   import schedule
   
   def daily_emergence_check():
       agent.force_emergence_check()
   
   schedule.every().day.at("00:00").do(daily_emergence_check)
   ```

3. **验证涌现结果**
   ```python
   result = trigger.trigger(EmergenceType.WISDOM)
   if result.success:
       # 验证能力有效性
       if not trigger.validate_capability(result.capability):
           print("能力验证失败，需要人工检查")
   ```

### 7.3 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 种子数量不增长 | 质量阈值过高 | 降低min_seed_quality |
| 涌现从不触发 | 阈值过高/时间窗口过短 | 调整emergence_config |
| 觉醒等级不晋升 | 条件不满足 | 检查required_types和emergences |
| 数据库报错 | 路径不存在 | 确保data目录存在 |

## 八、API参考

### 8.1 SeedCollector

```python
class SeedCollector:
    def extract(self, conversation: Conversation) -> List[RawSeed]
    def assess(self, seed: RawSeed) -> AssessedSeed
    def classify(self, seed: AssessedSeed) -> ClassifiedSeed
    def process(self, conversation: Conversation) -> List[ClassifiedSeed]
    def aggregate(self, seeds: List[ClassifiedSeed]) -> SeedBatch
```

### 8.2 AlayaStore

```python
class AlayaStore:
    def save_seed(self, seed: ClassifiedSeed) -> str
    def save_batch(self, seeds: List[ClassifiedSeed]) -> List[str]
    def get_seed(self, seed_id: str) -> Optional[ClassifiedSeed]
    def search_seeds(self, query: str, limit: int = 10) -> List[ClassifiedSeed]
    def get_statistics(self) -> SeedStatistics
    def record_emergence(self, ...) -> int
    def init_awakening_level(self, agent_id: str)
    def get_awakening_level(self, agent_id: str) -> Dict
```

### 8.3 EmergenceTrigger

```python
class EmergenceTrigger:
    def check(self, emergence_type: EmergenceType) -> EmergenceOpportunity
```
