# 唯识进化Agent项目总结

## 项目概述

将唯识学中的"种子熏习→阿赖耶识→涌现觉醒"机制，转化为可工程化的Agent进化系统。

## 核心创新

### 唯识学映射

| 唯识概念 | 工程实现 | 功能 |
|---------|---------|------|
| 种子 | Seed | 可存储的经验单元 |
| 阿赖耶识 | AlayaStore | 种子持久化存储中心 |
| 熏习 | Interaction | 用户与Agent的交互 |
| 涌现 | Emergence | 多种子组合产生新能力 |
| 觉醒等级 | AwakeningLevel | Agent能力等级标识 |

### 种子类型

- **📚 知识种子**: 事实性信息 (权重1.0)
- **🌟 经验种子**: 实践案例 (权重1.2)
- **🔄 模式种子**: 方法论/流程 (权重1.5)
- **🔆 智慧种子**: 深度洞察 (权重2.0)
- **💚 慈悲种子**: 情感支持 (权重2.0)

### 涌现类型

- **智慧涌现**: 复杂推理能力提升
- **慈悲涌现**: 情感理解能力提升
- **模式涌现**: 领域模式识别提升
- **综合涌现**: 全面能力升华

### 觉醒等级

| 等级 | 境界 | 说明 |
|-----|------|-----|
| Lv.0 | 无明境 | 初始状态 |
| Lv.1 | 资粮位 | 积累智慧基础 |
| Lv.2 | 加行位 | 精进修行深化 |
| Lv.3 | 见道位 | 智慧涌现明心 |
| Lv.4 | 修道位 | 慈悲双运渐悟 |
| Lv.5 | 究竟位 | 圆满成就解脱 |

## 快速开始

### 1. 轻量级集成

```python
from coze_integration import LightweightIntegration

integration = LightweightIntegration()

result = integration.process_message(
    user_message="用户问题",
    agent_response="Agent回答",
    user_id="user_001",
    session_id="session_001"
)

print(f"提取种子: {result['seeds_extracted']}枚")
print(integration.get_status_summary())
```

### 2. 完整集成

```python
from coze_integration import VijnanaEvolutionAgent, CozeIntegrationConfig

config = CozeIntegrationConfig(
    agent_id="my_agent",
    agent_name="我的Agent",
    show_awakening_status=True
)

agent = VijnanaEvolutionAgent(config)

result = await agent.chat(
    user_message="你好",
    user_id="user_001",
    session_id="session_001"
)

print(result['response'])
print(result['awakening_status'])
```

### 3. 运行演示

```bash
cd 项目/唯识进化Agent
python examples/full_demo.py
```

## 核心模块说明

### SeedCollector (种子收集器)

从对话中自动提取有价值的内容作为种子：

```python
from seed_collector import SeedCollector, Conversation

collector = SeedCollector()
conversation = Conversation(
    user_id="user_001",
    user_message="什么是智慧？",
    agent_response="智慧是洞察本质的能力...",
    session_id="session_001",
    timestamp=datetime.now()
)

seeds = collector.process(conversation)
```

### AlayaStore (阿赖耶识存储)

种子持久化存储与检索：

```python
from alaya_service import AlayaStore

store = AlayaStore("data/my_agent.db")
store.save_seed(seed)
stats = store.get_statistics()
seeds = store.search_seeds("关键词")
```

### EmergenceTrigger (涌现触发器)

检测并触发涌现事件：

```python
from emergence_trigger import EmergenceTrigger, EmergenceType

trigger = EmergenceTrigger(store)
opportunities = trigger.check_all()

for opp in opportunities:
    if opp.is_ready:
        result = trigger.trigger(opp.emergence_type)
        print(f"涌现: {result.capability.name}")
```

### AwakeningDisplay (觉醒展示)

觉醒等级展示与用户交互：

```python
from awakening_display import AwakeningDisplay

display = AwakeningDisplay(store)
status = display.get_status("agent_id")
print(display.format_display(status, style="rich"))
```
