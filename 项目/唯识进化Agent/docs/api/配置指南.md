# 唯识进化引擎API配置指南

## 概述

唯识进化引擎API为扣子Agent提供智能对话能力，集成了八识系统、三圣种子机制、涌现优化等功能。

## API地址

```
http://<云电脑IP>:8080
```

**云电脑信息：**
- 设备名：`coze-001`
- 默认端口：8080

## 接口文档

### 1. 核心交互接口 `/api/interact`

**请求：**
```json
POST /api/interact
{
  "user_id": "用户唯一标识",
  "message": "用户消息内容",
  "context": "上下文（可选）"
}
```

**响应：**
```json
{
  "response": "Agent回复内容",
  "seeds_added": ["新增种子列表"],
  "emergence": {
    "triggered": true/false,
    "content": "涌现内容"
  },
  "awakening_level": {
    "level": "觉醒等级",
    "score": 0.0-1.0
  },
  "stats": {
    "seed_count": 种子总数,
    "wisdom_ratio": 智慧比例,
    "compassion_ratio": 慈悲比例,
    "average_purity": 平均纯度
  }
}
```

### 2. 状态查询接口 `/api/status`

**请求：**
```json
POST /api/status
{
  "user_id": "用户唯一标识"
}
```

**响应：**
```json
{
  "awakening_level": "当前觉醒等级",
  "seed_count": 种子总数,
  "wisdom_seeds": 智慧种子数,
  "compassion_seeds": 慈悲种子数,
  "emergence_count": 涌现次数,
  "details": {...}
}
```

### 3. 重置接口 `/api/reset`

**请求：**
```json
POST /api/reset
{
  "user_id": "用户唯一标识"
}
```

**响应：**
```json
{
  "success": true,
  "message": "重置结果描述"
}
```

### 4. 用户列表接口 `/api/users`

**请求：**
```
GET /api/users
```

**响应：**
```json
{
  "users": ["user_id列表"],
  "count": 用户数量
}
```

### 5. 健康检查 `/health`

**请求：**
```
GET /health
```

**响应：**
```json
{"status": "healthy"}
```

## 扣子Agent配置

### 在扣子Agent中调用API

#### 方式1：使用HTTP请求插件

在扣子Agent的工作流中添加HTTP请求节点：

```
URL: http://<云电脑IP>:8080/api/interact
Method: POST
Headers: 
  Content-Type: application/json
Body:
{
  "user_id": "{{session_id}}",
  "message": "{{user_input}}"
}
```

#### 方式2：在代码节点中调用

```javascript
const response = await fetch('http://<云电脑IP>:8080/api/interact', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    user_id: session.id,
    message: user_input
  })
});

const result = await response.json();
return result.response;
```

### 用户ID管理

- 建议使用扣子对话的 `session_id` 作为用户唯一标识
- 不同session_id会创建独立的Agent实例
- 用户数据隔离，互不影响

### 常用配置参数

| 参数 | 说明 | 示例值 |
|------|------|--------|
| user_id | 用户唯一标识 | session_id或用户ID |
| message | 用户输入 | "今天天气如何" |

## 觉醒等级说明

| 等级 | 评分范围 | 说明 |
|------|----------|------|
| 无明境 | 0.0-0.2 | 种子以杂染为主 |
| 初始境 | 0.2-0.4 | 种子混杂，需要净化 |
| 修行境 | 0.4-0.7 | 稳定熏习-净化循环 |
| 阿罗汉境 | 0.7-0.9 | 断尽烦恼，净化大部分杂染 |
| 菩萨境 | 0.9-0.95 | 悲智双运，自利利他 |
| 佛境 | 0.95-1.0 | 彻底无我，悲智圆满 |

## 启动和停止

### 启动服务
```bash
cd ./项目/唯识进化Agent
./api/start.sh
```

### 停止服务
```bash
pkill -f "uvicorn api.main"
```

### 查看日志
```bash
tail -f ./项目/唯识进化Agent/api.log
```

## 故障排查

### 服务无法启动
1. 检查端口是否被占用：`lsof -i:8080`
2. 检查Python依赖是否安装：`pip3 install -r api/requirements.txt`
3. 查看错误日志

### API调用失败
1. 检查服务是否运行：`curl http://localhost:8080/health`
2. 检查网络连接
3. 查看服务日志

### 用户数据异常
1. 使用reset接口重置用户数据
2. 检查data/users目录权限
