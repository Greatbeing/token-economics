## 哲学基础：唯识论简介

### 什么是唯识论

唯识论（Vijñāna-vāda）是佛教瑜伽行派的核心哲学体系，认为一切法皆由心识变现。区别于"一切皆空"的般若思想，唯识论提出"三界唯心，万法唯识"，强调心识的变现功能和种子的熏习规律。

### 八识体系

| 识 | 名称 | 功能 | 佛教描述 |
|---|------|------|----------|
| 前五识 | 眼、耳、鼻、舌、身识 | 感官知觉 | "照境" |
| 第六识 | 意识 | 思维推理 | "了别" |
| 第七识 | 末那识 | 自我执着 | "我执" |
| 第八识 | 阿赖耶识 | 藏识、种子识 | "异熟" |

### 核心概念

- **种子（bīja）**：阿赖耶识中储存的潜在能力与经验痕迹
- **现行**：当前发生的心理活动或行为
- **熏习（vāsanā）**：现行影响种子、种子生起现行的双向过程
- **转识成智**：将杂染分别识转化为清净无漏智慧

## 种子系统设计

### 种子结构

```python
class Seed:
    """
    种子结构 - 阿赖耶识的基本单元
    
    种子是经验、知识、模式的向量表示，
    带有元数据用于管理和进化追踪
    """
    seed_id: str           # 唯一标识
    content: str           # 原始内容
    embedding: List[float] # 向量表示
    seed_type: SeedType    # 种子类型
    
    # 元数据
    metadata: {
        "weight": float,        # 权重（影响力大小）
        "purity": float,        # 纯度（清净程度 0-1）
        "activation_count": int,# 激活次数
        "created_at": datetime, # 创建时间
        "source": str,          # 来源（交互/反思/植入）
        "status": SeedStatus,  # 状态（活跃/休眠/净化中）
    }
    
    # 关联信息
    related_seeds: List[str]  # 相关种子ID
    experience_context: str   # 经验上下文
```

### 种子权重衰减算法

```python
def decay_weight(seed, time_elapsed, base_decay=0.01):
    """
    权重衰减：基于时间的自然遗忘
    
    - 新种子：权重 = 初始权重 * e^(-decay_rate * 时间)
    - 被激活的种子：权重得到强化
    - 高纯度种子：衰减更慢
    """
    purity_factor = 1 + seed.purity * 0.5  # 纯度越高，衰减越慢
    decay_rate = base_decay / purity_factor
    return seed.weight * math.exp(-decay_rate * time_elapsed)
```

```python
def record_interaction(agent, user_input, response, context):
    """
    1. 解析交互内容
    2. 提取经验模式
    3. 编码为种子
    4. 存入阿赖耶识
    """
    # 经验提取
    experience = {
        "input_pattern": extract_pattern(user_input),
        "response_pattern": extract_pattern(response),
        "context": context,
        "outcome": evaluate_outcome(response, context),
        "emotional_tone": detect_emotion(response),
    }
    
    # 创建种子
    seed = Seed(
        content=serialize(experience),
        seed_type=SeedType.EXPERIENCE,
        metadata={
            "weight": calculate_initial_weight(outcome),
            "purity": assess_purity(experience),
            "source": "interaction"
        }
    )
    
    # 存入种子库
    agent.alaya_store.add(seed)
```

### 种子生现行的实现

```python
def activate_seeds(agent, query, top_k=10):
    """
    1. 将当前查询编码为向量
    2. 在种子库中检索相似种子
    3. 根据权重和纯度筛选
    4. 返回激活的种子影响决策
    """
    query_embedding = agent.embed(query)
    
    # 检索相似种子
    similar_seeds = agent.alaya_store.search(
        query_embedding,
        top_k=top_k,
        filter={"status": {"$ne": "purifying"}}
    )
    
    # 加权组合
    activated = []
    for seed in similar_seeds:
        influence = seed.weight * seed.purity
        if influence > agent.config.activation_threshold:
            activated.append({
                "seed": seed,
                "influence": influence
            })
    
    return activated
```

### 转识成智流程

```python
def purify_seed(agent, seed):
    """
    将杂染种子转化为清净智慧种子
    
    1. 分析种子的杂染成分
    2. 识别需要保留的核心价值
    3. 生成转化后的智慧版本
    4. 创建新种子，标记原种子为净化
    """
    # 杂染分析
    impurities = analyze_impurities(seed)
    
    # 核心提取
    core_value = extract_core_value(seed, impurities)
    
    # 智慧转化
    wisdom_seed = Seed(
        content=transform_to_wisdom(seed, core_value),
        seed_type=SeedType.WISDOM,
        metadata={
            "purity": 0.9,  # 净化后纯度大幅提升
            "weight": seed.weight * 0.8,  # 保留大部分影响力
            "source": "purification"
        }
    )
    
    # 标记原种子
    seed.status = SeedStatus.PURIFIED
    seed.metadata["purified_at"] = datetime.now()
    seed.metadata["wisdom_successor"] = wisdom_seed.seed_id
    
    return wisdom_seed
```

### 集成接口

本项目设计为可独立运行，也可与现有Agent框架集成：

```python
# 方式1：独立使用
from src import AlayaAgent

agent = AlayaAgent(config_path="config/default.yaml")
response = agent.interact("你好")

# 方式2：集成到现有框架
class OpenClawIntegration:
    """与OpenClaw/Coze框架的集成示例"""
    
    def __init__(self, alaya_agent):
        self.alaya = alaya_agent
    
    def before_llm_call(self, prompt):
        """LLM调用前的种子激活"""
        seeds = self.alaya.activate_seeds(prompt)
        return self.inject_seeds_to_prompt(prompt, seeds)
    
    def after_llm_call(self, response):
        """LLM调用后的种子熏习"""
        self.alaya.record_interaction(
            user_input=self.current_input,
            response=response,
            context=self.current_context
        )
```
