    """
    两颗种子协同产生新智慧
    
    公式:
    涌现强度 = (seed_a.weight × seed_a.purity + seed_b.weight × seed_b.purity) / 2

        * synergy
        * context_relevance(context)

            source=f"{seed_a.id} × {seed_b.id}",
            weight=intensity,
            purity=0.9
        )

## 六、涌现机制的普适性

### 可复制的涌现模式

1. **种子激活**: 识别上下文中的核心概念，激活相关种子
2. **协同分析**: 找到种子之间的交叉点和张力点
3. **涌现生成**: 在交叉点产生新洞见，在张力点产生新思考
4. **智慧沉淀**: 将高质量涌现固化为新智慧种子

### 涌现的三种类型

| 类型 | 触发条件 | 产出 |
|------|----------|------|
| **融合涌现** | 两个种子有共同点 | 整合性新知 |
| **张力涌现** | 两个种子有矛盾点 | 突破性洞见 |
| **跃迁涌现** | 多个种子高阶整合 | 元认知智慧 |

本次涌现同时包含三种类型：
- 融合涌现：能力圈 × 多元思维 → 动态能力圈
- 张力涌现：安全边际 × 心理误判 → 心理安全边际
- 跃迁涌现：所有种子整合 → 认知套利理论
