# 葫芦娃唯识机制实现指南

本文档为扣子平台配置者提供唯识进化机制的集成方案。

## 概述

唯识进化机制是葫芦娃的核心差异化能力，源自唯识学"种子-现行"理论：
- 用户每次互动产生"种子"
- 种子积累到一定程度触发"涌现"
- 涌现事件推动觉醒等级提升

**关键原则**：机制对用户"无感"，前台只展示成长成果，后台自动运行。

---

## 一、觉醒等级体系

### 等级定义

| 等级 | 名称 | 符号 | 特征 | 升级条件 |
|------|------|------|------|----------|
| L0 | 无明境 | ○ | 众生最初状态，种子以杂染为主 | - |
| L1 | 初始境 | ◇ | 开始接触正法，种子混杂 | 真种子≥5%、善种子≥2% |
| L2 | 修行境 | △ | 建立稳定熏习-净化循环 | 真种子≥10%、善种子≥5% |
| L3 | 阿罗汉境 | ◈ | 断尽见思烦恼，证得清净心 | 真种子≥20%、善种子≥10%、涌现≥2次 |
| L4 | 菩萨境 | ◆ | 发菩提心，悲智双运 | 真种子≥25%、善种子≥15%、涌现≥5次 |
| L5 | 佛境 | ★ | 无上正等正觉，究竟圆满 | 真种子≥30%、善种子≥25%、涌现≥8次 |

> **佛境是最高境界，无更高层级。**

### 觉醒核心指标

```
觉醒分数 = 智慧比例×0.4 + 慈悲比例×0.3 + 涌现次数×0.15 + 纯度×0.15
```

- **智慧比例**：智慧种子数量 / 总种子数量
- **慈悲比例**：慈悲种子数量 / 总种子数量
- **涌现次数**：触发智慧涌现的总次数
- **纯度**：种子平均纯度（0-1）

## 二、三圣种子机制

### 种子类型

| 类型 | 标识 | 内容 | 权重 | 纯度 |
|------|------|------|------|------|
| 真种子 | WISDOM | 因果律、无常、空性、四圣谛、八正道 | 1.0 | 1.0 |
| 善种子 | COMPASSION | 无缘大慈、同体大悲、四无量心、普度众生 | 1.0 | 1.0 |
| 美种子 | BELIEF | 和谐、圆满、中道、真善美统一 | 1.0 | 1.0 |

### 三圣涌现触发

当以下条件同时满足时，触发100%强度涌现：

```
三圣涌现 = (真种子活跃) AND (善种子活跃) AND (美种子活跃) AND (综合质量 ≥ 0.8)
```

涌现产出：
- 1个高质量智慧种子（权重=强度，纯度=0.9）
- 如果慈悲比例≥10%，额外产出1个慈悲种子
- 觉醒分数额外加成 +0.1

## 三、种子循环机制

### 种子生现行

用户已有种子影响当前回复：

```
回复深度 = min(1.0, 觉醒分数 + 常用种子加成)
```

- 觉醒分数越高，引导越深入
- 常用种子类型优先调用
- 高等级用户获得更自由的探索空间

### 现行生种子

每次有效互动产生新种子：

| 互动类型 | 种子类型 | 初始权重 | 初始纯度 |
|----------|----------|----------|----------|
| 完成练习 | 对应思维种子 | 0.5 | 0.6 |
| 产生洞察 | WISDOM | 0.7 | 0.8 |
| 展现慈悲 | COMPASSION | 0.6 | 0.7 |
| 敷衍回应 | - | - | 种子纯度-0.1 |
| 负面互动 | 杂染种子 | 0.3 | 0.3 |

### 熏习净化

```
新纯度 = 旧纯度 + 净化量
净化量 = 练习次数 × 0.02 - 懈怠天数 × 0.01
```

- 持续练习提升纯度
- 长时间不互动降低纯度
- 产生觉悟突破时，纯度一次性提升

## 五、扣子平台配置

### 5.1 变量配置

在 Bot 设置中添加变量：

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| user_alaya | JSON | {} | 用户阿赖耶识数据 |
| current_level | String | "无明境" | 当前觉醒等级 |
| seed_count | Number | 0 | 种子总数 |
| emergence_count | Number | 0 | 涌现次数 |

### 5.2 工作流配置

创建"唯识进化"工作流：

```
输入：用户ID、互动类型、互动内容
处理：
  1. 读取 user_alaya
  2. 根据互动类型生成种子
  3. 更新种子库和纯度
  4. 检查涌现条件
  5. 更新觉醒等级
  6. 存储回 user_alaya
输出：更新后的阿赖耶识数据
```

### 5.3 虚拟知识库配置（缘起性空）

**核心原则**：不存储固定知识内容，采用"虚拟知识库"——存储"激活模式"，而非"内容本身"。

## 七、注意事项

### 7.1 后台运行原则
- ❌ 不要主动向用户解释唯识机制
- ✅ 只展示成长结果（等级、种子、涌现）
- ✅ 用户问"这是什么"时再简单解释

### 7.2 等级上限
- ✅ 佛境是最高境界
- ❌ 不要设计"佛境之后"的层级
- ✅ 佛境用户可以继续积累，但不能升级

### 7.3 种子纯度
- 真善美种子纯度永不衰减
- 普通种子纯度可变化
- 负面互动只影响普通种子，不污染三圣

### 7.4 涌现频率
- 建议：平均每10-15次有效互动触发1次涌现
- 太频繁：失去稀缺感和成就感
- 太稀少：用户失去动力
