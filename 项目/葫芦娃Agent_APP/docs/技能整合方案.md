# 葫芦娃技能整合方案

1. **圣哲思维引擎** - 东西方圣哲的思维模型库

## 二、唯识进化机制整合

### 2.1 种子系统

整合自「唯识进化Agent」项目的种子积累机制：

```python
# src/seed_tracker.py 核心逻辑

class SeedTracker:
    """
    思维种子追踪器
    记录用户的思维练习、种子积累、等级进化
    """
    
    def __init__(self, user_id: str):
        self.user_id = user_id
        self.seeds = {}  # 各思维类型的种子数量
        self.awakening_level = 1  # 觉醒等级
        self.history = []  # 练习历史
        
    def add_seed(self, thought_type: str, points: int = 1):
        """增加思维种子"""
        if thought_type not in self.seeds:
            self.seeds[thought_type] = 0
        self.seeds[thought_type] += points
        
        # 检查是否触发智慧涌现
        if self.seeds[thought_type] >= 5:
            return self.trigger_awakening(thought_type)
        return None
        
    def trigger_awakening(self, thought_type: str) -> dict:
        """触发智慧涌现事件"""
        self.awakening_level += 1
        return {
            "event": "智慧涌现",
            "thought_type": thought_type,
            "new_level": self.awakening_level,
            "message": f"你的{thought_type}种子集齐了！智慧涌现！"
        }
```

### 2.2 觉醒等级体系

| 等级 | 名称 | 解锁能力 | 升级条件 |
|------|------|----------|----------|
| L1 | 迷途者 | 基础对话 | 注册即得 |
| L2 | 觉醒者 | 思维匹配 | 任意种子达2颗 |
| L3 | 修行者 | 智慧涌现 | 任意种子达5颗 |
| L4 | 明智者 | 多维思考 | 3种以上种子达3颗 |
| L5 | 圣哲境 | 融会贯通 | 5种以上种子达4颗 |

### 2.3 进化计算

```python
# 觉醒等级计算
def calculate_awakening_level(seeds: dict) -> int:
    level = 1
    
    # 统计各水平种子数
    strong_seeds = sum(1 for v in seeds.values() if v >= 4)
    medium_seeds = sum(1 for v in seeds.values() if v >= 3)
    any_seeds = sum(1 for v in seeds.values() if v >= 2)
    max_seed = max(seeds.values()) if seeds else 0
    
    # L2: 任意种子达2颗
    if any_seeds >= 1:
        level = 2
    
    # L3: 任意种子达5颗
    if max_seed >= 5:
        level = 3
        
    # L4: 3种以上种子达3颗
    if medium_seeds >= 3:
        level = 4
        
    # L5: 5种以上种子达4颗
    if strong_seeds >= 5:
        level = 5
        
    return level
```

def evaluate_practice(thought_type: str, answers: list) -> dict:
    """
    评估用户练习答案
    返回详细评分和建议
    """
    scores = []
    feedbacks = []
    
    for i, answer in enumerate(answers):
        score, feedback = evaluate_single_answer(
            thought_type, 
            i, 
            answer
        )
        scores.append(score)
        feedbacks.append(feedback)
    
    avg_score = sum(scores) / len(scores)
    total_score = avg_score  # 满分5分
    
    return {
        "scores": scores,
        "avg_score": avg_score,
        "total_score": total_score,
        "feedbacks": feedbacks,
