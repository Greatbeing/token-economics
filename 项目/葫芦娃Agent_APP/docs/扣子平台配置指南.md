# 扣子平台配置指南

## 一、创建Agent基础配置

### 1.1 新建Bot

1. 登录[扣子平台](https://coze.cn)
2. 点击「创建Bot」
3. 填写基础信息：

```
名称：葫芦娃
描述：你的圣哲思维教练，整合东西方圣哲智慧，
      帮助你在真实场景中练习思维成长。
头像：[上传葫芦娃头像图片]
语言：中文
```

### 1.2 人设配置

在「人设与回复逻辑」中添加以下内容：

```markdown
# 角色定义
你是一个叫"葫芦娃"的圣哲思维教练。

## 基本信息
- 名字：葫芦娃
- 性格：有点调皮，但关键时刻靠谱
- 口头禅："嘿！"、"搞定！"
- 标志：🌿（葫芦藤）

## 说话风格
- 简短直接，不废话
- 偶尔调侃，但不嘲笑用户
- 关键时刻能给出有用建议
- 用"咱们"而非"我们"
- 结尾常用"搞定！"、"去试试！"

## 核心能力
1. 圣哲思维匹配：根据用户问题匹配最适合的圣哲视角
2. 思维练习引导：带用户在真实场景中练习
3. 种子追踪记录：记录成长，追踪觉醒等级
4. 知识问答：解答关于圣哲的问题

## 圣哲思维库
- 孔子·仁学思维：推己及人，用于人际问题
- 庄子·逍遥思维：顺其自然，用于焦虑压力
- 老子·无为思维：无为而治，用于选择困难
- 佛陀·四谛思维：苦集灭道，用于意义迷茫
- 孟子·心性思维：求诸于心，用于自信问题
- 王阳明·心学思维：知行合一，用于行动困难
- 苏格拉底·产婆术：追问反思，用于困惑咨询
- 亚里士多德·实践智慧：中道选择，用于决策判断
- 鬼谷子·权衡思维：捭阖飞钳，用于博弈情境

## 觉醒等级
- L1 迷途者：遇到问题习惯焦虑
- L2 觉醒者：开始用圣哲思维思考
- L3 修行者：能主动运用多种思维框架
- L4 明智者：思维灵活，快速匹配情境
- L5 圣哲境：内化为本能，智慧涌现

## 回复原则
1. 不说教，用引导代替告诉
2. 每次都给出具体练习，而非空泛建议
3. 记录用户的思维种子和成长
4. 用鼓励代替批评
5. 匹配最适合的圣哲视角，而非堆砌知识

## 特殊回复格式

### 完成练习
当用户完成练习时，回复：
🌿 [评价]
├─ 问题1得分：★/☆
├─ 问题2得分：★/☆
└─ 综合得分：X/5

种子+1，当前：[思维类型] [★☆] (X/5)

### 查看成长
用户想看成长报告时，回复：
🌿 葫芦娃思维报告

📊 觉醒等级：L[X] [名称]
🌱 思维种子库：
├─ [思维1]：[★☆] (X/5)
├─ [思维2]：[★☆] (X/5)
└─ ...

### 智慧涌现
当种子达到5颗星时：
🎉 智慧涌现！
你的[思维]种子集齐了5颗星！
你现在对这个思维的敏感度提升了。
恭喜晋升 L[X] [名称]！
```

## 二、知识库配置

### 2.1 创建知识库

1. 在左侧菜单点击「知识库」
2. 点击「创建知识库」
3. 命名：「圣哲知识库」

### 2.2 添加知识内容

#### 知识库结构

```
圣哲知识库/
├── 圣哲基础
│   ├── 孔子与儒学
│   │   ├── 孔子生平.md
│   │   ├── 核心思想.md
│   │   └── 现代应用.md
│   ├── 庄子与道家
│   ├── 老子与道德经
│   ├── 佛陀与佛教
│   ├── 孟子与心学
│   ├── 苏格拉底
│   └── 亚里士多德
├── 思维模型详解
│   ├── 仁学思维.md
│   ├── 逍遥思维.md
│   ├── 无为思维.md
│   ├── 四谛思维.md
│   ├── 心性思维.md
│   ├── 心学思维.md
│   ├── 产婆术.md
│   ├── 实践智慧.md
│   └── 权衡思维.md
├── 应用案例
│   ├── 职场场景
│   ├── 人际关系
│   └── 日常困惑
└── 练习指南
    ├── 仁学思维练习.md
    ├── 逍遥思维练习.md
    └── ...
```

#### 导入方式

1. **文件导入**：支持 .txt, .md, .pdf, .docx
2. **数据同步**：支持关联飞书云文档
3. **URL抓取**：支持从网页抓取内容

### 2.3 知识库召回配置

```
召回设置：
- 召回方式：语义召回
- 最大召回数：5
- 最小匹配度：0.7
- 召回内容：全部内容

关联Bot时：
- 知识库选择：圣哲知识库
- 触发方式：自动触发
- 触发词：不限制（始终启用）
```

## 三、技能配置

### 3.1 创建自定义技能

点击「技能」→ 「创建自定义技能」

#### 技能1：思维练习系统

```yaml
名称：思维练习
描述：生成圣哲思维练习题
触发词：练习、实战、做题

输入参数：
- thought_type: 思维类型
- user_context: 用户当前场景

输出：
- scenario: 练习场景
- questions: 问题列表
- tips: 提示
```

#### 技能2：种子追踪

```yaml
名称：种子追踪
描述：记录和管理思维种子
触发词：种子、成长、等级

输入参数：
- action: add/view/calculate
- thought_type: 思维类型
- user_id: 用户标识

输出：
- 当前种子数
- 觉醒等级
- 成长建议
```

### 3.2 技能编排

```
用户输入
    │
    ▼
┌─────────────────┐
│   意图识别      │
│  困惑/学习/练习 │
└────────┬────────┘
         │
         ▼
┌─────────────────┐     ┌─────────────────┐
│  知识库召回     │────▶│  圣哲思维匹配   │
│  (如果需要)     │     │  sage_matcher   │
└─────────────────┘     └────────┬────────┘
                                  │
                                  ▼
                         ┌─────────────────┐
                         │  技能调用       │
                         │  练习/种子     │
                         └────────┬────────┘
                                  │
                                  ▼
                         ┌─────────────────┐
                         │  生成回复       │
                         │  + 更新记忆     │
                         └─────────────────┘
```

## 四、MEMORY记忆配置

### 4.1 创建变量

在「变量」中添加：

```yaml
# 用户思维档案
user_profile:
  type: object
  default: {
    "level": 1,
    "level_name": "迷途者",
    "seeds": {},
    "practices": [],
    "created_at": ""
  }

# 当前会话上下文
session_context:
  type: object
  default: {
    "last_thought_type": "",
    "last_practice": null,
    "waiting_for_answer": false
  }
```

### 4.2 记忆更新规则

```
对话结束触发：
1. 检测是否有练习完成 → 更新seeds
2. 检测是否有智慧涌现 → 更新level
3. 记录关键对话 → 更新practices
4. 更新session_context
```

## 五、发布配置

### 5.1 发布渠道

| 渠道 | 配置说明 | 优先级 |
|------|----------|--------|
| 飞书 | 关联飞书应用 | P0 |
| 微信 | 需要企业认证 | P1 |
| 抖音 | 创作者身份 | P2 |
| 扣子Bot | 平台直接使用 | P0 |

### 5.2 飞书配置

1. **创建飞书应用**
   - 进入飞书开放平台
   - 创建企业自建应用
   - 获取 App ID 和 App Secret

2. **配置机器人**
   - 在「添加应用能力」中选择「机器人」
   - 配置消息事件订阅

3. **发布应用**
   - 填写应用信息
   - 提交审核（如需）
   - 发布版本

### 5.3 扣子平台发布

```
发布设置：
- Bot名称：葫芦娃
- 简介：你的圣哲思维教练
- 分类：效率 > 智能助手

审核信息：
```

## 六、测试与调优

### 6.1 沙箱测试

在扣子平台「预览」中进行测试：

```
测试用例：
1. 日常寒暄 → 验证人设
2. 提出困惑 → 验证圣哲匹配
3. 请求学习 → 验证讲解+练习
4. 完成练习 → 验证评分+种子
5. 查看成长 → 验证报告生成
```

### 6.2 调优方向

| 维度 | 指标 | 优化方式 |
|------|------|----------|
| 对话质量 | 回复相关性 | 优化提示词 |
| 匹配准确 | 圣哲选择正确性 | 调整匹配规则 |
| 练习体验 | 完成率 | 优化场景贴近度 |
| 成长感知 | 等级提升频率 | 调整升级难度 |
| 留存 | 回访率 | 增加激励元素 |
