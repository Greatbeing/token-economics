# 孔子与仁学思维

## 一、孔子简介

孔子（公元前551年—公元前479年），名丘，字仲尼，鲁国人。中国古代伟大的思想家、教育家，儒家学派创始人。

**核心贡献**：
- 创立儒学，奠定中国传统文化基础
- 提出"仁"的概念，构建道德哲学体系
- 开创私学，主张"有教无类"

## 二、仁学思维核心

### 什么是"仁"

**仁 = 推己及人 + 同理心 + 恰当行为**

三个层次：
1. **仁者爱人**：对他人有真诚的关爱
2. **推己及人**：己所不欲，勿施于人
3. **克己复礼**：约束自己，遵循恰当的行为规范

### 仁学思维流程

```
感知他人处境
    ↓
推己及人（如果我是他，我会怎么想？）
    ↓
选择恰当行为（怎样做既尊重自己，又善待他人？）
```

## 三、可复刻的技能

### 技能1：共情推理

**定义**：站在对方角度思考问题的能力

**练习方法**：
- 当与人冲突时，先问：他为什么这么做？
- 想象自己处于对方位置，会有什么感受
- 找出双方都能接受的解决方案

**场景示例**：
- 同事批评你的方案 → 他可能是为项目好 → 如何改进方案？
- 朋友迟到 → 他可能遇到困难 → 如何既表达不满又不伤关系？

### 技能2：关系思考

**定义**：思考人与人之间恰当关系的能力

**五伦框架**：
| 关系 | 恰当行为 |
|------|---------|
| 父子 | 父慈子孝 |
| 君臣 | 君仁臣忠 |
| 夫妇 | 夫义妇顺 |
| 长幼 | 长惠幼顺 |
| 朋友 | 朋友有信 |

**现代应用**：
- 上下级关系 → 尊重与负责
- 同事关系 → 合作与信任
- 朋友关系 → 真诚与支持

### 技能3：中庸决策

**定义**：在极端之间找到恰当平衡点的能力

**中庸三原则**：
1. **过犹不及**：太过和不够都不好
2. **执两用中**：在两个极端之间找平衡
3. **时中**：根据具体情况调整

**决策框架**：
```
识别两个极端
    ↓
分析当前情况
    ↓
找到适合当下的平衡点
    ↓
根据反馈调整
```

## 四、仁学思维练习

### 练习1：推己及人

**场景**：你的朋友借钱不还，你很生气。

**思考步骤**：
1. 他为什么借钱？（感知处境）
2. 如果是你借了钱还不还，你希望对方怎么做？（推己及人）
3. 怎样处理既能要回钱，又不伤友情？（恰当行为）

### 练习2：中庸决策

**场景**：老板让你加班，但你已经有重要安排。

**思考步骤**：
1. 两个极端是什么？（完全不加班 vs 无条件加班）
2. 当前情况是什么？（老板的紧急需求 vs 你的重要安排）
3. 平衡点是什么？（能不能换时间？能不能部分加班？）
