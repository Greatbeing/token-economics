# 圣哲思维引擎 - 项目概览

> 版本：v1.0 | 最后更新：2025-01-26

---

## 项目概述

**圣哲思维引擎** 是一个融合唯识进化机制的系统，旨在帮助青少年复刻东西方圣哲的思维能力。

### 核心目标

1. **提炼** - 从80万字圣哲知识库中提取可操作的思维模型
2. **复刻** - 让青少年通过刻意练习复刻圣哲的思维方式
3. **进化** - 融合唯识学原理，构建可生长的思维种子系统
4. **涌现** - 支持多种思维协同，产生新智慧

## 思维等级体系

| 等级 | 名称 | 特征 |
|------|------|------|
| L1 | 蒙昧 | 习惯性思维，无反思 |
| L2 | 觉察 | 能察觉自己的思维模式 |
| L3 | 理解 | 能理解并描述思维模型 |
| L4 | 运用 | 能在指导下运用思维模型 |
| L5 | 熟练 | 能独立运用，自动触发 |
| L6 | 融通 | 能融合多种思维模型 |
| L7 | 觉醒 | 能涌现新理解 |
| L8 | 圆觉 | 智慧圆满，自度度人 |
