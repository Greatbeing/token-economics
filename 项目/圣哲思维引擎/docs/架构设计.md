## 一、设计愿景

### 1.1 核心使命
让青少年能够**复刻**东西方圣哲的思维能力，通过刻意练习将圣哲智慧内化为自己的思维本能。

### 1.2 核心价值
- **传承**：将80万字圣哲知识库蒸馏为可操作的思维模型
- **进化**：融合唯识学原理，构建可生长的思维种子系统
- **普惠**：让每个青少年都能获得圣哲级别的思维训练

### 1.3 设计原则
1. **可复刻**：每个思维模型都必须有明确的练习路径
2. **可衡量**：思维成长可量化、可追踪、可可视化
3. **可涌现**：支持多种思维模型的协同，产生新智慧
4. **青少年友好**：趣味性强，门槛低，成就感高

#### 3.4.1 场景匹配引擎 (Scene Matcher)

**功能**：将用户问题/场景与思维模型进行智能匹配

```python
class SceneMatcher:
    def __init__(self):
        self.scene_classifier = SceneClassifier()
        self.model_index = ModelIndex()
        self.context_analyzer = ContextAnalyzer()
    
    def match(self, user_input: str) -> MatchResult:
        """
        输入：用户的问题或场景描述
        输出：匹配的思维模型列表 + 匹配理由
        """
        # 1. 场景分类
        scene_type = self.scene_classifier.classify(user_input)
        
        # 2. 提取关键要素
        elements = self.context_analyzer.extract(user_input)
        
        # 3. 计算模型匹配度
        candidates = self.model_index.search(scene_type, elements)
        
        # 4. 返回排序结果
        return self.rank_and_filter(candidates)
```

#### 3.4.2 对话引导系统 (Dialogue Guide)

**功能**：通过苏格拉底式提问，引导用户使用思维模型

```python
class DialogueGuide:
    def __init__(self):
        self.question_templates = QuestionTemplateLibrary()
        self.dialogue_state = DialogueStateMachine()
        self.thinking_prompter = ThinkingPrompter()
    
    def guide(self, model: ThinkingModel, user_context: str) -> DialogueSession:
        """
        引导用户完成一个思维模型的练习
        """
        session = DialogueSession(model)
        
        # 开场：介绍模型价值
        session.add_message("system", self._intro_message(model))
        
        # 第一步：引发问题
        session.add_message("assistant", self._ask_problem_intro(model))
        
        # 循环：苏格拉底式提问
        while not session.is_complete():
            user_response = session.wait_for_input()
            next_question = self._generate_next_question(
                model, 
                session.history,
                user_response
            )
            session.add_message("assistant", next_question)
            
            # 适时提示思维步骤
            if session.need_hint():
                session.add_message("assistant", self._provide_hint(model))
        
        # 收尾：总结与肯定
        session.add_message("assistant", self._conclusion(model, session))
        
        return session
```

#### 3.4.4 涌现检测系统 (Emergence Detector)

**功能**：检测用户的思维是否产生"涌现"——多思维协同产生新智慧

```python
class EmergenceDetector:
    """
    借鉴唯识学的'涌现'概念：
    - 当多种思维种子同时活跃且协同工作时
    - 可能产生超越单一思维的新理解
    - 这被称为'涌现'或'顿悟'
    """
    
    def __init__(self):
        self.threshold_calculator = ThresholdCalculator()
        self.synergy_analyzer = SynergyAnalyzer()
        self.insight_detector = InsightDetector()
    
    def detect(self, user_seed_state: SeedState, context: Context) -> EmergenceResult:
        """
        检测是否发生思维涌现
        """
        # 1. 检查多种子协同
        active_seeds = [s for s in user_seed_state if s.activity > 0.5]
        
        if len(active_seeds) < 2:
            return EmergenceResult(no_emergence=True)
        
        # 2. 计算协同度
        synergy = self.synergy_analyzer.calculate(active_seeds)
        
        # 3. 检查是否达到涌现阈值
        threshold = self.threshold_calculator.get_threshold(
            user_seed_state.level,
            context.difficulty
        )
        
        if synergy >= threshold:
            # 4. 检测涌现内容
            insight = self.insight_detector.detect(
                active_seeds,
                user_seed_state.recent_responses
            )
            return EmergenceResult(
                has_emergence=True,
                insight=insight,
                involved_seeds=active_seeds
            )
        
        return EmergenceResult(no_emergence=True)
```

#### 等级跃迁机制
```python
class LevelAdvancement:
    """
    等级跃迁规则
    
    借鉴唯识学：
    - 种子需要不断熏习才能现起
    - 达到一定熏习量才能发生质变
    """
    
    def __init__(self):
        self.thresholds = {
            'L1_to_L2': {'practices': 5, 'insights': 0},
            'L2_to_L3': {'practices': 15, 'insights': 1},
            'L3_to_L4': {'practices': 30, 'insights': 2},
            'L4_to_L5': {'practices': 50, 'insights': 3},
            'L5_to_L6': {'practices': 80, 'insights': 5, 'synergy_required': True},
            'L6_to_L7': {'practices': 120, 'insights': 8, 'emergence_required': True},
            'L7_to_L8': {'practices': 200, 'insights': 15, 'contribution_required': True},
        }
    
    def check_advancement(self, user: UserState) -> AdvancementResult:
        """检查是否可以跃迁"""
        current_level = user.level
        next_level = f"L{int(current_level[1]) + 1}"
        
        requirements = self.thresholds.get(f"{current_level}_to_{next_level}")
        if not requirements:
            return AdvancementResult(can_advance=False)
        
        # 检查各项指标
        checks = {
            'practices': user.total_practices >= requirements['practices'],
            'insights': user.total_insights >= requirements['insights'],
        }
        
        if 'synergy_required' in requirements:
            checks['synergy'] = user.synergy_events >= 3
        
        if 'emergence_required' in requirements:
            checks['emergence'] = user.emergence_count >= 1
        
        if all(checks.values()):
            return AdvancementResult(
                can_advance=True,
                next_level=next_level,
                celebration=True
            )
        
        return AdvancementResult(can_advance=False, progress=checks)
```

class AwakeningProgress:
    """
    觉醒进度展示
    
    借鉴唯识学：觉醒 = 阿赖耶识的净化与智慧显现
    """
    
    def __init__(self):
        self.awakening_dimensions = [
            '智慧',      # 对真理的认知
            '慈悲',      # 对众生的关怀
            '勇气',      # 面对困难的担当
            '自在',      # 心灵的解脱
            '创造',      # 智慧的运用
        ]
    
    def calculate_awakening(self, user_state: UserState) -> AwakeningState:
        """
        计算觉醒进度
        """
        awakening = {}
        
        for dimension in self.awakening_dimensions:
            # 根据用户在各维度的表现计算觉醒度
            dimension_score = self._calculate_dimension(
                dimension, 
                user_state
            )
            awakening[dimension] = dimension_score
        
        # 综合觉醒度
        awakening['total'] = sum(awakening.values()) / len(awakening)
        
        return AwakeningState(
            dimensions=awakening,
            description=self._generate_description(awakening),
            next_milestone=self._get_next_milestone(awakening)
        )
