# 圣哲思维模型框架

> 版本：v1.0 | 状态：设计阶段 | 最后更新：2025-01-26

---

## 一、框架概述

### 1.1 设计目标

思维模型框架是将圣哲智慧**可操作化**的核心设计。它解决了三个关键问题：

1. **提取什么**：从圣哲知识中提取哪些可复刻的思维元素
2. **如何结构化**：用什么数据结构来组织思维模型
3. **如何使用**：如何让用户通过练习真正掌握这些思维

### 1.2 设计原则

| 原则 | 说明 | 示例 |
|-----|------|-----|
| 可理解 | 概念清晰，易于理解 | 用"推己及人"代替"恕道" |
| 可练习 | 有明确操作步骤 | 设计具体的练习场景 |
| 可衡量 | 掌握程度可评估 | 设置评估维度和标准 |
| 可组合 | 可与其他模型协同 | 定义模型间的关联关系 |

## 三、思维流程设计规范

### 3.1 流程设计原则

1. **步骤数量**：每个流程3-7步为宜
2. **步骤命名**：使用行动词+宾语的简洁形式
3. **可逆性**：步骤之间应有逻辑关联
4. **可反馈**：每个步骤都有问题提示

### 3.2 流程模板

```python
class ThinkingFlow:
    """
    思维流程模板
    
    每个思维流程包含：
    - 步骤列表：有序的思维操作
    - 每个步骤：名称、描述、提示问题、专注技能
    """
    
    template = {
        "flow_name": "{流程名称}",
        "steps": [
            {
                "step_id": 1,
                "step_name": "{动词+宾语}",
                "description": "{操作的详细说明}",
                "question_prompt": "{引导思考的问题}",
                "skill_focused": "{该步骤培养的核心技能}",
                "common_pitfall": "{常见错误}",
                "tip": "{小提示}"
            }
        ],
        "flow_type": "linear|cycle|branch"
    }
```
