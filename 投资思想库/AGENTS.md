# 投资思想库 AGENTS.md

## 知识库使命
搜集、整理、研究古今中外投资大师的思想精华，建立系统化的投资智慧知识库。

## 目录结构

```
投资思想库/
├── AGENTS.md           # 本规则说明书
├── raw/                # 原始素材（大师原著、演讲、访谈原文）
├── wiki/
│   ├── INDEX.md        # 知识索引总览
│   ├── 人物档案/       # 每位大师的独立档案
│   └── 主题分类/       # 按投资主题分类整理
└── outputs/            # 生成的报告和分析
```

## 内容规范

### 人物档案结构
每位大师档案必须包含：
1. **人物简介** - 生平、成就、代表作品
2. **核心投资哲学** - 主要思想体系
3. **主要投资策略** - 具体操作方法
4. **代表案例** - 经典投资案例分析
5. **经典语录** - 原话引用，标注出处
6. **关联主题** - 使用[[主题名]]链接到主题分类

### 主题分类结构
每个主题文档包含：
1. **主题定义** - 概念解释
2. **核心原理** - 基本逻辑
3. **代表人物** - 关联到人物档案
4. **实践方法** - 具体应用
5. **经典案例** - 应用实例

## 引用规范
- 所有观点必须标注出处
- 优先引用：原著 > 官方演讲 > 权威传记 > 新闻报道
- 格式：`「原文」——来源《书名》/演讲/访谈`

## 质量标准
- 信息准确：反复核实，交叉验证
- 原文优先：优先保留大师原话
- 关联清晰：使用[[链接]]建立知识网络
- 持续更新：随新发现补充完善
