# 风险管理

> "投资的第一原则是不要亏损，第二原则是记住第一原则。"

## 主题定义

**风险管理**是投资成功的核心要素，涵盖识别、评估、控制投资过程中可能面临的各类风险，确保本金安全并追求稳健回报。

## 核心原理

### 1. 本金安全优先

格雷厄姆的核心理念：

> "投资的本质是对风险的管理，而非对收益的预测。"

**核心原则**：
- 永远不要冒资本永久损失的风险
- 避免追求高收益而承担过高风险
- 本金安全是投资的第一原则

### 2. 安全边际

格雷厄姆的风险缓冲机制：

> "安全边际是投资的基石，没有安全边际的投资，就像在薄冰上行走。"

**安全边际的作用**：
- 为判断错误提供缓冲空间
- 为市场波动提供保护垫
- 降低永久性资本损失概率

**实践标准**：
- 买入价格比内在价值低30%-50%
- 寻找"五毛钱买一块钱"的机会

### 3. 风险识别

投资中的主要风险类型：

| 风险类型 | 描述 | 来源 |
|---------|------|------|
| **市场风险** | 系统性波动影响 | 整体市场下跌 |
| **企业风险** | 经营不善导致损失 | 管理层、竞争等 |
| **估值风险** | 价格高于价值 | 过度乐观 |
| **流动性风险** | 无法及时变现 | 低流动性资产 |
| **心理风险** | 情绪化决策 | 贪婪、恐惧 |

## 代表人物的风险观

### 格雷厄姆——安全边际至上

> "用五毛钱的价格，去买价值一块钱的东西。"

**风险控制方法**：
- 定量筛选：PE≤15，PB≤1.5
- 分散投资：持有10-30只股票
- 股债平衡：25%-75%动态调整

---

### 巴菲特——多重防线

> "投资的第一原则是不要亏损，第二原则是记住第一原则。"

**风险控制方法**：
1. **能力圈**：只投资能理解的企业
2. **护城河**：选择可持续竞争优势企业
3. **安全边际**：以合理价格买入
4. **长期持有**：让复利发挥作用
5. **现金储备**：保持弹药等待机会

---

### 芒格——误判心理学

芒格总结了25种人类常见心理误判：

| 类型 | 描述 | 投资影响 |
|-----|------|---------|
| **损失厌恶** | 对亏损的痛苦超过盈利的快乐 | 持有亏损太久 |
| **过度自信** | 高估自己的判断能力 | 集中押注 |
| **从众心理** | 跟随大众判断 | 追涨杀跌 |
| **锚定效应** | 被历史价格锚定 | 错过机会 |
| **确认偏误** | 只看支持自己的证据 | 忽视风险 |

---

### 达利欧——系统化风控

> "痛苦+反思=进步。"

**风险平价策略**：
- 让每类资产对组合风险贡献相等
- 配置10-15个低相关性资产
- 降低整体组合风险60%-80%

## 风险管理工具

### 1. 仓位管理

| 方法 | 说明 | 适用场景 |
|-----|------|---------|
| **固定仓位** | 每只股票相同比例 | 保守型投资者 |
| **金字塔法** | 低位重仓，高位减仓 | 趋势投资者 |
| **核心-卫星** | 核心70%+卫星30% | 平衡型投资者 |
| **风险平价** | 风险贡献相等 | 机构投资者 |

### 2. 止损策略

**止损原则**：
- 设定最大亏损容忍度（如-20%）
- 基本面恶化时果断止损
- 区分暂时下跌与永久损失

**止损方法**：
| 方法 | 说明 |
|-----|------|
| **固定止损** | 亏损达到固定比例卖出 |
| **跟踪止损** | 上涨后提高止损线 |
| **基本面止损** | 基本面变化时卖出 |

### 3. 分散投资

**分散维度**：
- **行业分散**：避免单一行业风险
- **地域分散**：降低地区风险
- **资产分散**：股票、债券、商品等
- **时间分散**：定投降低择时风险

## 风险评估框架

### 定量指标

| 指标 | 计算 | 风险提示 |
|-----|------|---------|
| **最大回撤** | 历史最大亏损 | 极端风险 |
| **波动率** | 收益率标准差 | 短期波动 |
| **夏普比率** | (收益-无风险)/波动率 | 风险调整收益 |
| **盈亏比** | 平均盈利/平均亏损 | 盈利质量 |

### 定性评估

| 维度 | 评估内容 |
|-----|---------|
| **商业模式** | 护城河强度 |
| **财务健康** | 现金流、负债率 |
| **管理层** | 诚信与能力 |
| **行业地位** | 竞争格局 |
