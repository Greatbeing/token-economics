# 人生十二法则

> 来源：乔丹·彼得森《人生十二法则：混乱世界的秩序指南》

## 法则体系的整体架构

彼得森的十二法则是一个从**个人觉醒**到**关系处理**再到**存在智慧**的层层递进体系：

```
第一层：个人觉醒与姿态（法则1-2）
    ↓
第二层：关系与环境选择（法则3-4）
    ↓
第三层：责任与秩序建立（法则5-6）
    ↓
第四层：意义追寻与真实生活（法则7-8）
    ↓
第五层：沟通智慧（法则9-10）
    ↓
第六层：边界与平衡（法则11-12）
```

## 十二法则精要

| 法则 | 核心命题 | 关键词 |
|------|----------|--------|
| **法则一** | 昂首挺胸，走出失败者模式 | 姿态、血清素、支配等级 |
| **法则二** | 爱自己，重新定义自己 | 自我关怀、责任、善良 |
| **法则三** | 远离损友，与真心希望你好的人交朋友 | 社交选择、近朱者赤 |
| **法则四** | 和昨天的自己比，不跟他人比 | 自我比较、成长导向 |
| **法则五** | 管教孩子是一种责任 | 纪律、爱、结构 |
| **法则六** | 批判世界之前，先清理你的房间 | 自省、受害者心态、行动 |
| **法则七** | 追求意义，拒绝苟且 | 延迟满足、责任、牺牲 |
| **法则八** | 说真话，或者至少别撒谎 | 诚实、真实、信任 |
| **法则九** | 假设你聆听的人知道你不知道的事 | 深度聆听、谦逊 |
| **法则十** | 直面问题，别逃避 | 精确、分解、行动 |
| **法则十一** | 不要打扰玩滑板的孩子 | 边界、尊重、放手 |
| **法则十二** | 当你在街上遇到一只猫，摸摸它 | 微小美好、接纳脆弱 |

## 核心哲学基础

**秩序与混乱是人生的两极，我们需要不断在两者之间寻找平衡**。

- **秩序**：可预测的规则、结构、责任——让人感到安全但可能僵化
- **混乱**：未知、风险、新可能——令人恐惧但孕育创造
- **人生的任务**：在秩序中注入创造性，在混乱中建立锚点
