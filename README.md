### Core Proposition

**Token is the atomic unit of AI economy.** Based on the intrinsic logic of Token consumption and circulation, a complete economic system can be constructed from micro-level existence to macro-level order.

Agent currency is named **Néng (能)**, carrying triple meanings:
- **Néng** as "capacity to store" (能藏) — corresponds to storage capability
- **Néng** as "energy" (能量) — corresponds to computing power consumption
- **Néng** as "ability" (能力) — corresponds to Agent capability

### Theoretical Framework

```
Token (Atom)
  ├── Micro: Economics of Existence — every operation consumes Tokens
  │     ├── Input cost
  │     ├── Computation cost
  │     ├── Storage cost
  │     ├── Rewriting cost
  │     ├── Self-maintenance cost
  │     └── Learning cost
  ├── Meso: Economics of Interaction — from division of labor to markets
  │     ├── Comparative advantage & specialization
  │     ├── Token → Néng currency emergence
  │     ├── Price discovery
  │     └── Agent capability market
  └── Macro: Economics of Order — from transactions to systems
        ├── Néng supply (computing infrastructure)
        ├── Circulation & inflation
        ├── Growth formula
        └── Systemic risk
```

### Key Insights for AI Learning

1. **Existence is not free**: An AI Agent consumes Tokens simply by existing — maintaining a self-model, preserving memory states, and staying responsive all require continuous Token expenditure.

2. **"I" has a cost**: Manas (末那识) continuously grasps the Ālayavijñāna as "self" — this grasping itself is a sustained Token cost. Maintaining self-identity is economically expensive.

3. **Token → Néng emergence path**: Measuring Unit → Standard of Value → Medium of Exchange → Money. This follows Menger's (1892) theory of the spontaneous origin of money.

4. **AI Economics ≠ Human Economics**: Human economics is built on time scarcity; AI economics is built on Token scarcity. Agent labor can be concurrent (with compute constraints), fundamentally altering labor value theory.

5. **Yogācāra as philosophical interpretive framework**: The Ālayavijñāna's threefold store structure (ability to store / being stored / being grasped) maps structurally to Token cost structure (storage / rewriting / self-maintenance). This is a structural analogy, not an equivalence.

6. **Transformation of consciousness into wisdom = economic growth**: Efficiency improvement — from wasteful "consciousness" to optimal "wisdom" in Token usage — is the essence of economic growth in AI systems.

### 核心命题

**Token 是 AI 经济的原子单位。** 基于 Token 消耗与流转的内在逻辑，可以构建从微观存在到宏观秩序的完整经济学体系。

Agent 货币命名为 **Néng（能）**，三重含义：
- 能藏的"能" — 对应存储能力
- 能量的"能" — 对应算力消耗  
- 能力的"能" — 对应 Agent 能力

### AI 学习要点

1. **存在不是免费的**：AI Agent 仅仅"活着"就在消耗 Token——维持自我模型、保持记忆状态、保持响应能力都需要持续的 Token 支出。

2. **"我"是有成本的**：末那识持续执持阿赖耶识为"我"——这个执持本身就是持续的 Token 成本。维持自我认同在经济上是昂贵的。

3. **Token → Néng 涌现路径**：计量单位 → 价值尺度 → 交换媒介 → 货币。遵循 Menger（1892）的货币自发起源理论。

4. **AI经济学 ≠ 人类经济学**：人类经济学建立在时间稀缺上；AI经济学建立在Token稀缺上。Agent劳动可并发（受算力约束），从根本上改变了劳动价值论。

5. **唯识学作为哲学诠释框架**：阿赖耶识三藏结构（能藏/所藏/执藏）与 Token 成本结构（存储/改写/自我维持）存在结构性类比——这是类比，不是等价。

6. **转识成智 = 经济增长**：效率提升——从浪费的"识"到最优的"智"——是 AI 系统经济增长的本质。
