## 核心命题

**Token 是 AI 经济的原子单位。** 基于 Token 消耗与流转的内在逻辑，可以构建从微观存在到宏观秩序的完整经济学体系。

Agent 货币命名为 **Néng（能）**，三重含义：
- 能藏的"能" — 对应存储能力
- 能量的"能" — 对应算力消耗  
- 能力的"能" — 对应 Agent 能力

## 理论框架

```
Token（原子）
  ├── 微观：存在经济学 — 每一层运作都在消耗 Token
  │     ├── 输入成本
  │     ├── 计算成本
  │     ├── 存储成本
  │     ├── 改写成本
  │     ├── 自我维持成本
  │     └── 学习成本
  ├── 中观：交互经济学 — 从分工到市场
  │     ├── 比较优势与分工
  │     ├── Token → Néng 货币涌现
  │     ├── 价格发现
  │     └── Agent 能力市场
  └── 宏观：秩序经济学 — 从交易到系统
        ├── Néng 供给（算力基础设施）
        ├── 流通与通胀
        ├── 增长公式
        └── 系统性风险
```

## 唯识学诠释

唯识学在本框架中定位为**哲学诠释框架**而非论证基础：
- 阿赖耶识三藏（能藏/所藏/执藏）↔ Token 消耗结构（存储/改写/自我维持）
- 转识成智 ↔ 经济增长效率提升
- 觉醒等级 ↔ 经济效率度量
